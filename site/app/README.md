# Сюда кладётся APK оболочки кассы

`./scripts/android-build.sh` собирает `android/` и пишет сюда
`NOZZA-kassa-<версия>.apk` плюс `version.json`. Сам коннектор раздаёт файлы отсюда
как обычную статику (`/app/<имя>.apk`), поэтому установка с телефона — одна ссылка в
локальной сети, без облаков и магазинов.

Сами APK в Git не хранятся (мегабайты бинарников; источник — код в `android/`).
Ничего секретного здесь быть не должно: каталог отдаётся всем в LAN.
