Связь ценника с кассой и 1С

  1. В карточке позиции стеллажа укажите штрихкод ровно как в номенклатуре 1С. Если стеллаж связан с номенклатурой PrintFlow, код подставится оттуда.
  2. Скачайте «CSV для 1С» и сверьте или загрузите колонки «Артикул», «Штрихкод», «Наименование», «Цена». Конкретное сопоставление полей выбирается в вашей конфигурации 1С.
  3. Распечатайте ценник. Кассовый сканер прочитает Code 128 и найдёт этот же код в 1С.
  4. Необязательно: после проведения чека 1С может отправить строку продажи в PrintFlow. Деньги второй раз не записываются — уменьшается только остаток стеллажа.
POST /api/shelf/1c/sale Content-Type: application/json {"barcode":"4601234567890","qty":1,"price":590,"external_id":"ККМ-000184:1"}

external_id — уникальный ID строки чека. Повторная отправка с тем же ID безопасна и не спишет товар дважды.
