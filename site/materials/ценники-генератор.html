✏️ Ручной ценник — клик по любому ценнику для редактирования

Выбрано: нет — клик по ценнику Ручных: 0
Клик по ценнику → поля заполняются, можно править название, цену, описание, бейдж, QR. Город Симферополь по умолчанию сохраняется в браузере (nozza:contact). Ручные ценники хранятся локально (nozza:priceCustom) и попадают на печать первыми. Пустые бланки — для ручного вписывания.
Как печатать: масштаб 100 %, без «вписать в лист», бумага 160–250 г/м² или самоклеящаяся плёнка A4. Клик по ценнику выделяет его (синяя рамка) и переносит в редактор. Можно указывать информацию самостоятельно в полях выше — цена, материал, бейдж, QR. Если каталог PrintFlow не открыт, покажется демо-набор. Город по умолчанию — Симферополь.
