РЕКОМЕНДУЕМЫЙ ЗАПУСК НА WINDOWS
───────────────────────────────────────────────────────────────

  Дважды кликните:  ЗАПУСТИТЬ-Windows.bat

  При первом запуске потребуется интернет: скрипт создаст отдельное
  Python-окружение в %LOCALAPPDATA%\PrintFlow и установит MQTT-клиент.
  В репозиторий зависимости и секреты не записываются.

  Затем откроется:  http://localhost:8080/#printer

  Не закрывайте чёрное окно, пока работаете с мониторингом принтера.
  Для остановки нажмите Ctrl+C или закройте окно.


ПЕРВОЕ ПОДКЛЮЧЕНИЕ P1S
───────────────────────────────────────────────────────────────

  1. Компьютер и принтер должны быть в одной локальной сети.
  2. В PrintFlow откройте «Принтер» → «Подключить P1S».
  3. Нажмите «Найти в сети» либо введите вручную:
       • локальный IP-адрес принтера;
       • Serial Number;
       • LAN Access Code.
  4. Эти значения смотрите на экране P1S: Settings → WLAN/Network.
  5. На новой защищённой прошивке для полного управления может
     потребоваться LAN Only Mode + Developer Mode.
  6. Нажмите «Сохранить и подключить» и подождите 5–10 секунд.

  ВАЖНО: LAN Only / Developer Mode может отключить Bambu Cloud и
  Bambu Handy. PrintFlow ничего не переключает автоматически — режим
  меняется только вами на экране принтера.

  Если связь нестабильна, закройте вкладку Device в Bambu Studio:
  некоторые версии P1S ограничивают число локальных MQTT-клиентов.


БЕЗОПАСНОСТЬ
───────────────────────────────────────────────────────────────

  • PrintFlow Connector по умолчанию слушает только 127.0.0.1.
  • Не открывайте порты 8080, 8883, 6000 или 990 на роутере.
  • Access Code хранится в %APPDATA%\PrintFlow\config.json.
  • Код не сохраняется в браузере и не попадает в Git/резервную копию.
  • Остановка, нагрев, скорость и другие опасные команды требуют
    подтверждения в интерфейсе.
  • Для удалённого доступа используйте VPN, а не проброс портов.


ЧТО ПОКАЗЫВАЕТ BAMBU LAB LIVE
───────────────────────────────────────────────────────────────

  • доступность принтера, прошивка и Wi-Fi;
  • текущее задание, прогресс, слой и оставшееся время;
  • температуры сопла, стола и камеры;
  • скорости вентиляторов и режим печати;
  • слоты AMS, типы, цвета, влажность и активный слот;
  • HMS и код ошибки печати;
  • локальную камеру P1S;
  • историю старта, пауз, завершений, ошибок и команд;
  • связь реальной печати с заказом PrintFlow.

  Остаток катушки, показываемый AMS, является оценкой производителя,
  а не результатом взвешивания. Фактическую мощность без умной розетки
  принтер также не передаёт.


TELEGRAM И WINDOWS
───────────────────────────────────────────────────────────────

  В настройках принтера можно локально указать Bot Token и Chat ID.
  Токен не вводите в чат и не добавляйте в файлы репозитория.

  Windows-уведомления отправляет браузер. При первом сохранении
  настроек разрешите уведомления для localhost.


ОБЫЧНЫЙ ОФЛАЙН-РЕЖИМ
───────────────────────────────────────────────────────────────

  Можно по-прежнему дважды кликнуть site/index.html. Заказы,
  калькуляторы, ниши и библиотека будут работать и сохраняться.
  Но живое состояние, камера и управление P1S будут недоступны,
  потому что браузер не умеет напрямую подключаться к MQTT/TLS.


MAC / LINUX
───────────────────────────────────────────────────────────────

  Запустите:  ЗАПУСТИТЬ-Mac-Linux.command

  Скрипт создаст окружение в ~/.local/share/printflow и запустит тот же
  локальный коннектор. На macOS может понадобиться разрешить выполнение:

      chmod +x ЗАПУСТИТЬ-Mac-Linux.command
