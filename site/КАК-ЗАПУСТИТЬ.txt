ГЛАВНОЕ ОБ ЭТОЙ ВЕРСИИ
───────────────────────────────────────────────────────────────

  Все данные теперь хранятся не в браузере, а в базе на вашем
  компьютере: %APPDATA%\PrintFlow\printflow.sqlite3

  Поэтому PrintFlow нужно ОТКРЫВАТЬ ЧЕРЕЗ ФАЙЛ ЗАПУСКА.
  Если просто дважды кликнуть index.html, интерфейс откроется,
  но данные не загрузятся и не сохранятся — вверху появится
  предупреждение «Коннектор недоступен».

  Данные старой версии не потеряются: смотрите раздел ПЕРЕНОС
  в конце файла.


ЗАПУСК НА WINDOWS
───────────────────────────────────────────────────────────────

  Дважды кликните:  ЗАПУСТИТЬ-Windows.bat

  При первом запуске нужен интернет: скрипт создаст отдельное
  Python-окружение в %LOCALAPPDATA%\PrintFlow и установит
  MQTT-клиент. В репозиторий зависимости и секреты не пишутся.

  Затем откроется:  http://localhost:8080

  Не закрывайте чёрное окно, пока работаете. Для остановки
  нажмите Ctrl+C или закройте окно.


ЗАПУСК НА MAC / LINUX
───────────────────────────────────────────────────────────────

  Запустите:  ЗАПУСТИТЬ-Mac-Linux.command

  Скрипт создаст окружение в ~/.local/share/printflow.
  На macOS может понадобиться разрешить выполнение:

      chmod +x ЗАПУСТИТЬ-Mac-Linux.command

  Вручную:  python3 connector/printflow_connector.py
  Другой порт:  python3 connector/printflow_connector.py --port 9000


ПЕРВОЕ ПОДКЛЮЧЕНИЕ ПРИНТЕРА
───────────────────────────────────────────────────────────────

  1. Компьютер и принтер должны быть в одной локальной сети.
  2. Откройте раздел «Принтеры» → кнопка «＋ Принтер».
  3. Нажмите «Найти принтеры» либо введите вручную:
       • локальный IP-адрес принтера;
       • Serial Number;
       • LAN Access Code.
  4. Эти значения смотрите на экране принтера: Settings → WLAN.
  5. На новой защищённой прошивке для полного управления может
     потребоваться LAN Only Mode + Developer Mode.
  6. Нажмите «Сохранить и подключить» и подождите 5–10 секунд.

  ВАЖНО: LAN Only / Developer Mode может отключить Bambu Cloud и
  Bambu Handy. PrintFlow ничего не переключает автоматически —
  режим меняете только вы на экране принтера.

  Если связь нестабильна, закройте вкладку Device в Bambu Studio:
  некоторые прошивки ограничивают число локальных MQTT-клиентов.

  Принтеров можно добавить несколько: они переключаются
  вкладками, а очередь печати общая на весь парк.


ЧТО МОЖНО ДЕЛАТЬ С ПРИНТЕРОМ
───────────────────────────────────────────────────────────────

  Мониторинг:
    • состояние, задача, прогресс, слой, оставшееся время;
    • температуры сопла, стола и камеры;
    • вентиляторы, скорость печати, Wi-Fi, прошивка;
    • слоты AMS: тип, цвет, остаток, влажность;
    • HMS и код ошибки печати;
    • локальная камера.

  Управление (с подтверждением):
    • пауза, продолжение, стоп, свет, скорость;
    • температуры сопла и стола, обдув детали;
    • парковка и перемещение осей, подача и выгрузка филамента;
    • калибровка стола, вибраций, полная калибровка;
    • назначение типа пластика в слот AMS.

  Файлы и печать:
    • список 3MF/G-code на SD-карте (FTPS, порт 990);
    • загрузка файла перетаскиванием;
    • запуск печати с выбором плиты, слотов AMS и калибровок;
    • очередь заданий с ручным или автоматическим запуском.


АВТОМАТИЧЕСКИЙ УЧЁТ
───────────────────────────────────────────────────────────────

  Печать началась  → создаётся задание, заказ переходит
                      в статус «Печать».
  Печать закончена → записываются граммы и минуты, пластик
                      списывается с катушки активного слота AMS,
                      считаются энергия и износ, обновляется
                      себестоимость заказа.
  Заказ закрыт     → в кассу попадает доход.

  Любой из шагов отключается в «Настройках → Автоматизация».
  Ваши ручные правки автоматика не перетирает.

  Остаток катушки, показываемый AMS, — оценка производителя,
  а не результат взвешивания. Точнее считает склад PrintFlow.


БЕЗОПАСНОСТЬ
───────────────────────────────────────────────────────────────

  • Сервер по умолчанию слушает только 127.0.0.1.
  • Не открывайте порты 8080, 8883, 6000 или 990 на роутере.
  • Access Code и Telegram-токен лежат только в каталоге данных
    и не попадают в браузер, Git и резервную копию.
  • Опасные команды требуют подтверждения в интерфейсе,
    а сервер проверяет допустимые пределы.
  • Для удалённого доступа используйте VPN, а не проброс портов.


ГОРЯЧИЕ КЛАВИШИ
───────────────────────────────────────────────────────────────

  Ctrl+K   командная палитра: разделы, действия и поиск
  N        новый заказ
  /        поиск


РЕЗЕРВНАЯ КОПИЯ И ПЕРЕНОС СТАРЫХ ДАННЫХ
───────────────────────────────────────────────────────────────

  Настройки → Данные:

    • «Скачать копию» — JSON со всеми заказами, клиентами,
      складом, финансами и журналом печати (без секретов).
      Делайте это раз в неделю.
    • «Восстановить» — загрузка копии обратно.
    • «Перенести из браузера» — забирает данные старой версии
      PrintFlow из localStorage этого браузера и переносит их
      в базу. Откройте страницу в том браузере, где работали
      раньше, и нажмите эту кнопку один раз.

  Резервная копия старого формата тоже принимается кнопкой
  «Восстановить».
