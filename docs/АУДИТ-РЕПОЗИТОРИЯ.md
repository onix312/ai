## Осознанные ограничения, не являющиеся дефектами

- Основной запуск `pf.py` доступен в LAN для работы с телефона; прямой
  `printflow_connector.py` безопаснее и слушает только `127.0.0.1`.
- PIN/роли в домашней LAN не вводятся по принятому продуктовому решению.
  Публиковать порт в интернет нельзя; удалённый доступ — только через VPN.
- Фронтенд остаётся без сборщика и внешних JS-библиотек: это требование
  автономности, а не недостающая настройка.
- Bambu Cloud и Telegram — согласованные внешние интеграции. Остальные данные
  и вычисления остаются локальными.

## Оставшийся технический долг

### Высокий приоритет

1. **Разделить `api.py`.** Методы `get` и `post` — крупные диспетчеры маршрутов
   (около 1 400 строк вместе). Следующий безопасный шаг — таблица маршрутов и
   модули `api_orders`, `api_printers`, `api_finance` без изменения URL.
2. **Потоковая загрузка multipart.** Текущий upload допускает 400 МБ, но
   разбирает тело в памяти. Для слабых компьютеров нужен временный файл и
   потоковый parser с тем же API.
3. **Настоящий browser E2E.** Сейчас хорошо проверяются HTML-контракты и
   синтаксис, но нет Playwright-сценария «создать заказ → очередь → оплата».
   Добавление браузерной зависимости требует отдельного решения, так как
   проект принципиально минимизирует внешние инструменты.
4. **Проверка миграции секретов.** Старые открытые Access Code читаются ради
   совместимости и шифруются при следующем сохранении. Можно добавить явную
   одноразовую миграцию после резервной копии.

### Средний приоритет

- Удалить или реализовать зарезервированные ключи настроек, которые пока не
  показаны пользователю: `slicer_filename_template`, `queue_smart_*`,
  `camera_timelapse_interval`, `camera_roi_center`, `ui_start_view`,
  `backup_auto_export`. Ключи пока сохранены для совместимости бэкапов.
- Разбить `manager.py` и `accounting.py` по доменам после стабилизации API.
- Добавить измерение покрытия тестами; сейчас главный показатель — сценарии,
  а не процент строк.
- Проверить PyInstaller-сборку и нативное окно на реальных Windows/macOS.
- Провести hardware-in-the-loop проверку на P1S + AMS и обеих схемах связи.

## Продуктовые вопросы владельцу

Эти решения нельзя достоверно вывести из кода:

1. Нужен ли в следующей итерации PIN для LAN, если панель используется не
   только в доверенной домашней сети?
2. Как трактовать НДС в цене: включён в цену или начисляется сверху? Пока
   система только предупреждает о пороге и не обещает автоматический расчёт.
3. Нужна ли автоочередь Watch Folder по умолчанию или безопаснее оставить
   текущий режим `notify`?
4. Что важнее для следующего этапа: декомпозиция API, потоковая загрузка или
   browser E2E?
