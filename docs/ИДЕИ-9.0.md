# Идеи PrintFlow 9.0 — цех, склад пластика, SD-карта (24.08.2026)

Новая нумерация **101–201** относится к пакету «цех 9.0». Это **не** те же
номера, что в `ИДЕИ-124.md` (там 101–124 — генераторы витрины 8.5).

Ограничения учёта 3.0, которые пакет не нарушает:

- второго «устного» остатка нет: «магазин / дом» — ярлык места, не склад;
- пластик приходуется только документом (`workshop_docs` / `shopping.receive`);
- печать только после подтверждения оператора и preflight;
- без облачного CRM, без автопостинга в соцсети, без zip всего `cache/` (109).

Оценка: ⚡ до полудня · ◐ день · ▣ несколько заходов.

## Статусы

- **✅ в 9.0.0** — сделано в этой версии;
- **⏸ на полке** — описано, можно брать позже;
- **❌ не берём** — противоречит правилам или явно запрещено.

## Что сознательно не делаем

- 109 — архивировать весь `cache/` принтера.
- Облачный CRM, автопостинг, рилсы, Авито-конвейер (это не пакет 9.0).
- Второй регистр остатка «магазин vs дом».
- Печать без preflight / без подтверждения.
- Автостарт заданий с `no_auto`.

## API 9.0

GET: `/api/workshop/about|inventory|enough|docs|doc|scrap|suppliers|presets|shift|slots|qr|label`,
`/api/printer/preview`, файлы с `path` + `crumbs`.

POST: `/api/workshop/location|slot|scrap|receipt|clone|no-auto|mixed-label|shift`,
`/api/workshop/supplier/*`, `/api/workshop/preset/*`.

## Схема 12

Таблицы: `workshop_docs`, `ams_slot_history`, `filament_scrap`, `suppliers`,
`plate_presets`, `shift_checks`.

Колонки: `spools.location|location_note|price_per_kg|received_doc_id`,
`print_jobs.start_request_id|mixed_label|no_auto|plate_preset_id`,
`shopping_items.receipt_doc_id|price_per_kg`.
