# Нативный интерфейс NOZZA (PySide6)

NOZZA имеет отдельный нативный интерфейс для Windows. Мозг ассистента остаётся
в процессе `agent`; GUI не импортирует `Brain`, `Runner` или базу напрямую и
работает через закрытые loopback API.

## Компоненты

- **Tray** — статус агента, модели и микрофона; Quick Panel, Control Center,
  включение/выключение микрофона, перезапуск UI и выход.
- **Voice Orb** — компактный always-on-top индикатор состояний
  listening / thinking / speaking / error.
- **Quick Panel** — окно быстрой текстовой команды. По умолчанию открывается
  глобальным `Ctrl+Shift+Space` на Windows.
- **Full Control Center** — разговор, день, ожидающие задачи, память, обучение,
  навыки, журнал и настройки.

HTML-страница `http://127.0.0.1:8799/ui` не удалена и остаётся fallback и
диагностическим интерфейсом.

## Установка

Из корня репозитория:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r agent\requirements.txt
```

Обычный запуск:

```bat
python -m agent
```

Агент поднимет порты 8791/8799 и автоматически откроет PySide6 UI, если
`PRINTFLOW_ASSISTANT_WINDOW` не выключен.

Можно запустить только интерфейс к уже работающему агенту:

```bat
python -m agent.native_ui
```

Если backend ещё стартует, UI не падает: tray показывает offline и автоматически
переподключается.

## Границы

Нативный UI не делает действий в обход safety-модели агента. Команда идёт в
`POST /chat`; write/high-risk навыки продолжают попадать в существующую очередь
подтверждений. Микрофон управляется отдельным speech-портом 8791.

Закрытие Control Center только прячет окно. Фоновый agent core, напоминания,
память и голос продолжают работать. Полный выход выполняется через tray.

## Проверка

Без GUI:

```bat
python -m unittest connector.tests.test_native_ui
```

На Windows вручную:

1. Запустить `python -m agent`.
2. Убедиться, что появился tray NOZZA.
3. Нажать `Ctrl+Shift+Space`, отправить «который час».
4. Открыть Control Center и проверить разделы «Память», «Обучение», «Навыки»,
   «Журнал».
5. Включить микрофон из tray и проверить появление Voice Orb.
6. Завершить agent core и убедиться, что UI показывает offline, затем запустить
   core снова и дождаться автоматического reconnect.


### Задачи и Task Engine

Раздел «Задачи» объединяет два слоя: долговечные Task Engine задачи и текущие
карточки safety-подтверждений. Для persistent-задач видны статус, прогресс и
ошибка/причина паузы; доступны запуск, продолжение, пауза и отмена.

UI не исполняет шаги сам. Все команды уходят в agent core через `/tasks`, а
реальное действие всё равно проходит через `Agent.run_skill`.
