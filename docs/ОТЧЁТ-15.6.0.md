# Отчёт — «Склад 15.6.0»: пластик в заказах и привязка AMS к складу

Дата: 2026-09-04. Версия: **15.5.0 → 15.6.0**.

Два запроса заказчика в этом раунде: (1) в заказе выбирать пластик со
склада и задавать его в граммах, чтобы корректно считалась стоимость;
(2) катушку, которую показывает AMS, можно было привязать к уже
заведённой катушке на складе. Плюс банк из 100 идей по складу.

## Что сделано

### 1. Стоимость заказа по фактическим катушкам

Форма заказа уже позволяла выбрать катушки и указать граммы (блок
«Катушки»), но смета пластик считала по справочной цене материала. Теперь:

- **Фактическая цена.** Если в заказе выбраны катушки, себестоимость
  пластика = сумма по строкам (граммы × цена катушки ÷ её вес) по
  реальным ценам и остаткам склада. Мультицвет (дешёвый PLA + дорогой
  TPU) считается точно. Катушки не выбраны — справочная цена, как раньше.
- **Граммы по каждой катушке** задаются явным числом; автораспределение
  общего веса заказа и подстановка из AMS уже работали.
- **Мягкое предупреждение о нехватке.** Если на выбранных катушках
  суммарно меньше граммов, чем нужно, в смете жёлтая строка
  «не хватает N г». Заказ не блокируется (решение заказчика).
- Смета пересчитывается при смене катушки и правке граммов; в строке
  видно «Пластик посчитан по фактическим катушкам склада: X ₽».
- Работает и в экономике сохранённого заказа (`order_economics`):
  катушки читаются и из JSON-строки БД, и из списка с фронта.

### 2. Привязка катушки AMS к складской

Раньше новая катушка в AMS всегда создавала «фантом» (без цены/бренда,
не верифицирован) — заведённая на складе катушка дублировалась. Теперь:

- На карточке катушки из AMS (стоит в слоте, не верифицирована, без
  цены/бренда) — кнопка **«🔗 Складская»**. Открывается выбор из
  катушек склада (с материалом, цветом, остатком и ценой за кг).
- После привязки на складскую катушку переезжают: слот принтера
  (`printer_id`/`ams_slot`), `tray_uuid`, AMS-синхронизация, история
  списаний `filament_usage` и ссылки в заказах (`orders.spools`).
  Дальше AMS обновляет остаток уже складской катушки.
- **Остаток и цена — складские** (решение заказчика): склад остаётся
  источником правды по учёту. Фантом архивируется (не удаляется, чтобы
  сохранить историю и события).
- Защита: привязать на слот, у которого уже есть другая активная
  катушка, нельзя; одна и та же катушка — нельзя; несуществующие
  цели отклоняются. Отвязать слот можно существующими механизмами.

### 3. Банк идей — `docs/ИДЕИ-СКЛАД-100.md`

100 идей, разбитых по 13 темам (корректировки, резервы, склады,
оборотка, инвентаризация, полка, пластик, заказы, закупки, аналитика,
аудит/права, бот/мобильность, UI), с оценкой стоимости 🟢/🟡/🔴 и
пометками о сделанном.

## Проверки

- 12 новых тестов — все зелёные: фактическая цена по катушкам (в т.ч.
  мультицвет с разными ценами), нехватка граммов, пропуск отсутствующих
  катушек, `cost_breakdown` с `filament_cost`, экономика заказа из JSON
  и из списка; привязка AMS: переезд слота/tray/синхронизации, остаток
  и цена складские, фантом в архиве, перенос истории и ссылок в заказах,
  отказы (та же катушка, нет цели, занятый слот).
- Полный прогон: **1252 теста, без падений** (3 пропуска — пред-существующие).
- `py_compile` всех модулей и `node --check ops.js/money.js` — OK.
- Живой смоук через HTTP (порт 8092): катушка 1000 ₽/кг → смета 100 г =
  100 ₽ пластика по факту; запрос 990 г при остатке 950 → нехватка 40 г;
  фантом AMS привязан к складской — слот 2/tray/локация переехали,
  остаток 950 г и цена 1000 ₽ сохранены, фантом пропал из активных.

## Сценарий приёмки в панели

1. Заказы → новый заказ → блок «Катушки»: «+ Катушка» → выбрать катушку
   со склада, задать граммы. Посмотреть смету: пластик по фактической
   цене; при нехватке — жёлтое предупреждение.
2. Склад пластика: карточка катушки из AMS (значок ⟳ AMS, «⚠ проверить»,
   без цены) → кнопка «🔗 Складская» → выбрать заведённую катушку →
   «Привязать». Проверить: слот и история на складской, фантом исчез.

## Не вошло (для следующих раундов)

Полка-стеллаж единым контуром со складом (идеи 44–50); выбор катушек
прямо из карточки заказа при привязке; авто-подбор катушек (FEFO);
мастер инвентаризации со сканером; роли/пин в панели. Банк идей готов
к выбору приоритетов.
