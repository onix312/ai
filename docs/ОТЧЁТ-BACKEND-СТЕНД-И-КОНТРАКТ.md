- Клиент локальной модели ограничивает **сумму символов** системного текста, истории и последнего запроса. Последний запрос сохраняется целиком; избыточная старая история не попадает в вызов модели.

## Владелец данных и маршруты

| Данные / действие | Единственный владелец | Путь и правила |
|---|---|---|
| Заказы, материалы, задания, состояние принтеров, деньги | Коннектор панели | На Windows `%APPDATA%/PrintFlow/printflow.sqlite3`; клиент панели работает через API, не открывает БД напрямую |
| Память и диалог помощника панели | Коннектор панели | Таблицы `assistant_memory`, `assistant_dialog` в базе панели |

| Команды принтеру и финансовые действия | Серверный каталог панели | Ассистент возвращает предложение; выполнение идёт по существующим правилам подтверждения панели |
| Действия на компьютере | Реестр навыков агента | Агент проверяет доступность, параметры и подтверждение; панель только передаёт запрос |
| Вопрос агента о мастерской | Панель через loopback | `POST /api/assistant/chat`, `delegate:false`, отдельная сессия агента; обратная делегация запрещена |

### Контракт версии 1

Вход в `POST /api/assistant/chat` панели и `POST /chat` агента:

```json
{"contract_version":1,"request_id":"UUID-или-короткий-ID","session":"main","text":"Сколько заказов сегодня?"}
```

Ответ содержит `contract_version: 1`, тот же `request_id` и `status`. Если ID отсутствует либо недопустим, сервер создаёт новый. Версия выше 1 отклоняется. Старый запрос без `contract_version` трактуется как версия 1. Предыдущие поля ответа (`kind`, `reply`, `action`, `params`, `steps`, `source`) сохраняются.

Значения `status` на этом этапе: `completed`, `needs_clarification`, `needs_confirmation`, `failed`; у агента дополнительно `unhandled`, когда он передаёт вопрос дальше. `completed` означает завершение текущего маршрута ответа и не доказывает, что внешнее устройство подтвердило команду. Различение «отправлено/выполнено/результат неизвестен» относится к последующей задаче A05.

`request_id` служит для связи этапов одного запроса в журналах; он не является разрешением на выполнение и не отменяет проверку подтверждения. `delegate:false` в запросе агента к панели оставляет защиту от цикла. При запросе панели к агенту тот же ID передаётся дальше. Два хранилища диалогов пока сохраняются: объединение памяти и схем БД не требовалось для этого среза.

## Воспроизводимый стенд

Команда из корня проекта: `python scripts/assistant-stand.py`.

Пример фактического результата текущего запуска:

| Проверка | Результат |
|---|---|
| Папка | `C:\Temp\printflow-assistant-stand-eu0_p800` |
| База панели | `PrintFlow/printflow.sqlite3` внутри папки стенда |
| База агента | `agent/assistant.db` внутри папки стенда |
| Копия и восстановление | `backup/panel.sqlite3` → `restored/panel.sqlite3` |
| Целостность восстановленной БД | `ok`, 100 таблиц |
| Рабочая база / принтеры | Скрипт их не читает и не вызывает |

Файл `stand.json` в папке стенда содержит пути и результат проверки. Для повторной проверки создаётся новая папка; скрипт не удаляет старые стенды. Папки содержат только синтетические данные и могут быть удалены после разбора результатов.

Рабочую БД можно восстанавливать только отдельной процедурой с резервной копией, сохранением операций после её создания и остановкой записей на время переключения. Здесь операция восстановления выполнена исключительно на синтетической копии.

## Контекст: до и после

Воспроизводимый пример: системный текст 8000 символов, восемь старых реплик примерно по 5000 символов, последний запрос 1999 символов. Транспорт модели подменён локальной заглушкой; реальные данные не передавались.

| Показатель | До | После |
|---|---:|---:|
| Текст в запросе модели | 22 400 символов | 9 999 символов |
| Последний запрос | 400 из 1999 символов | 1999 из 1999 символов |
| Общий бюджет 12 000 символов | превышен | соблюдён |

Алгоритм сохраняет последний пользовательский запрос, затем системные правила в пределах отдельной квоты и помещающиеся последние реплики. Если новый запрос сам длиннее бюджета, возвращается понятная ошибка. Длинный системный текст сохраняет начало и конец; середина, где может находиться часть каталога, удаляется. Следующая задача A03 отберёт короткий каталог навыков до вызова модели, чтобы такая потеря стала редкой.
