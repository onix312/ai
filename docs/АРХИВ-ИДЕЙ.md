- денежный контур (цены, себестоимость, предоплата, долги, комиссии, платежи,
  касса, смены, возвраты) — отдельным раундом.

## Как этим пользоваться

1. Перед новой идеей — поиск по каталогам: `grep -rn "нужные слова" docs/ИДЕИ-*.md`.
2. Если идея уже есть в каталоге — берём её номер, а не новую формулировку.
3. Закрытый каталог не источник задач: он объясняет, почему сделано так.
4. Числа в этой таблице сверяет `connector/tests/test_ideas_archive.py`:
   появился новый каталог или старый вырос — индекс устарел, тест скажет.
