**Статус:** готово (3 задачи захода). Базис — `main` после merge PR #111
(18.5.0): версия, shell-v69 и 134 файла тестов перепроверены командами
из промта до старта. Расхождение базиса: `assets/app.js` в `site/index.html`
запинен на 17.0.13, а не на 18.5.0, как сказано в промте (проверено —
трогать не стал, файл не менялся).

### Задача 1. Вариация = полноценный товар

**Сервер:** колонки `nom_variants.brand/description/photos_json`
(кортежи в `ADDED_COLUMNS` + `CREATE TABLE` в `schema_v3.py`, старые базы
догоняются); галерея `var_{id}.jpg` (обложка, прежнее имя — старые раздачи
отдают те же байты) + `var_{id}_{n}.jpg`; методы `variant_gallery`,
`add/delete_variant_photo`, `set_variant_cover`, `variant_card`
(строка + галерея + экономика + живой слот AMS); маршруты
`GET /api/nomenclature/variant/card`,
`POST /api/nomenclature/variant/photos|photos/delete|cover`;
кадры — `GET /api/nomenclature/variant/photo.jpg?n=` (без `n` — обложка).

**Интерфейс:** модалка `variant_modal` (полный набор полей, hex-пикер,
селект катушки, экономика с наценкой и кВт·ч, блок AMS со слотом и
кнопкой «В слот…»/«Отвязать»); кнопка ✎ в строке вариации; сетка строки
починена (в 18.5 фото-кнопка не влезла в 6 колонок — 7-й элемент
переносился). Быстрые правки (катушка, цена) остались в строке;
счётчик «N шт» живой. Энергия — расчётная из экономики (отдельной
колонки нет: она функция часов, а не свойство вариации).

**Совместимость:** касса (`variant_photo_url`) и бот видят обложку
прежним адресом; без состава — поведение 18.5.0; касса и бот не тронуты
в денежных путях.

### Задача 2. AMS-индикаторы

**Бак:** одна функция `PFSpoolColor.tank()` (`site/assets/colors.js`,
чистая — прогоняется в node), один CSS `.pf-tank`
(`site/assets/tokens.css`, размеры md/sm/xs, состояния low/empty).
Стоит в трёх местах: карточка катушки (md, был `.reel`), остаток товара
(sm, был `.prod-donut`), слот AMS (xs, был текст `.pc`) + пульт
(`site/control.html`, карточка слота). Мёртвый CSS кружков удалён.

**Многоцвет (дефект Б):** слот красится `swatchCss(bound, x.color)` —
двойные цвета, градиент, радуга, шёлк-2; сырой hex принтера — только без
привязки (снят риск №5 из отчёта 18.5.0). Та же замена — в трубке
вкладки AMS (заливка + бирка) и в чипе слота пульта. Подсказки
`queue.js`/`ops.js` — только текст, дублей рендера нет (проверено).
Трубка детального вида оставлена компонентой (это не кружок), но цвет
берёт из общего свотча.
