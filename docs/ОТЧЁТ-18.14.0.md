## Что просили и что выбрали

Владелец: «нужен именно личный ассистент на ПК», больше взаимодействия с системой целиком — файлы, окна, приложения, ввод, звук, экран, календарь, деньги, память. PrintFlow — одна из подсистем, а не центр. Фильтр прежний: реализуемо на ПК цеха (Windows, Bambu с AMS, камера, микрофон, локальные модели, чужие приложения ОС), инварианты репозитория сохранены — никаких облаков, данные машину не покидают, внешняя программа со своим окружением `agent/` — допустимый узор.

Выборы владельца (три волны):

## Что сделано

### Ядро: реестр навыков, своя база, окно

- `agent/skills.py` — реестр как данные: 18 навыков, поля `name/title/description/host/risk/params/requires/ideas/doc`, типы параметров `text/int/float/bool/date/path/object/oneof`, риски `read/own/write/system/irreversible`, хосты `agent/panel`, способности `files/sqlite/panel/model/windows/uia/ocr/screen/camera/speech_in/speech_out/printer/tray`. `confirm_required` — из риска, выученный — всегда с подтверждением. `availability` — причина из `capabilities`, а не выдумка. `catalog` — весь реестр с доступностью, `prompt` — только доступные для модели. `check_params` — только объявленные имена, мусор отбрасывается с предупреждением. `learn` — `my.*`, только существующие навыки, не выученные, max 8 шагов, риск max, requires union, параметров нет, имя не может занять встроенное. `validate` — самопроверка реестра.
- `agent/store.py` — своя SQLite `~/.printflow/assistant.db` (env `PRINTFLOW_ASSISTANT_DB`): `journal` (at, skill, outcome, detail, target, params JSON), `documents` (path PK, kind, title, size, mtime, digest, chunks, indexed_at), `chunks` (path, seq, first_line, text), `facts` (at, path, kind, value, place, used), `notes` (at, text, due, done), `skills` (name PK, payload JSON, learned_at). `pylower` — casefold для русского. Методы: `journal`, `journal_recent` (clamp 1..500), `last_outcome`, `unchanged`, `put_document` (транзакция документ+чанки), `forget_document`, `documents`, `known_paths`, `search` (оценка из совпадений слов + бонус заголовка), `put_facts`, `facts`, `mark_fact_used`, `add_note`, `open_notes`, `close_note`, `save_skill`, `learned_skills`, `forget_skill`, `stats`.
- `agent/documents.py` — чтение без зависимостей: `.txt/.md/...` как есть с fallback cp1251, `.docx/.xlsx` как zip+XML через regex, `.gcode` только комментарии и M104/M109/M140/M190/M106, `.stl` бинарный (имя из заголовка + число треугольников) и текстовый (count facet normal, проверка до длины заголовка, bugfix bytes casefold), `.pdf` честно требует pypdf, фото — причина с «зрением» (идея И164). `is_knowledge` — папки `знания`/`knowledge` или слово в имени, `docs/` — только внутри репозитория (иначе тестовая папка `docs` считалась бы знаниями). `chunks_of` с first_line, `tokens_of` без стоп-слов, `walk` без служебных папок и скрытых, `index` — только изменённые (размер, mtime, хеш начала), забывает исчезнувшие, `facts_from_text` — детерминированные суммы ₽, даты, телефоны, почты, количества, номера с местом строка N.
- `agent/fileops.py` — раскладка загрузок: `NAME_RULES` (Счета, Договоры, Заказы, Модели, Чертежи) бьют `SUFFIX_RULES` (Модели .stl/.3mf/.obj/.step..., Нарезка .gcode, Фото .jpg/.png..., Архивы, Установщики, Документы). `allowed_roots` из `config.file_folders`, `_resolve` без `..`, `inside_allowed` с причиной, `destination_for` с объяснением, `unique_target` с `(2)` без перезаписи, `plan` — rglob всех файлов, прямые — кандидаты на перемещение (проверка скрытых, размера >512 МБ, назначения), файлы в подпапках назначения — «уже лежит в папке назначения», в других подпапках — «в подпапке — не трогаем», `execute` — только внутри той же папки, удаления нет, чужой план не уедет.
- `agent/panel_client.py` — loopback-клиент панели: `loopback_ok`, `_request` с причиной, `multipart` для загрузки файла в заказ, `Client` с `status`, `alive`, `actions`, `find_action`, `run_action` (адрес, метод и confirm из каталога панели, confirmed ставит человек), `ask`, `day`, `upload_to_order` (черновик, сохраняет человек).
- `agent/model.py` — рантайм текста: loopback, stdlib, `status`, `complete`, `numbers_checked` (цифры ответа против источника), `parse_json`.
- `agent/executor.py` — порядок: существует → доступен → параметры → подтверждение → журнал. `describe` — фраза для окна подтверждения (fix для object param). `Runner` с ленивым Store, `refresh_capabilities` (detect + dynamic панель и модель), `learned`, `catalog`, `run` (неизвестный навык — «нет в реестре» с подсказкой, параметры только объявленные, confirmed в параметрах не существует, выученный с шагами проверяет доступность по шагам, чтение успешное в журнал не пишется). `_dispatch` 18 обработчиков, `_run_steps` — шаги подряд с остановкой на первом отказе. `panel.do` берёт confirm из каталога панели. `files.*` проверяют границу папок. `files.tidy_plan` — план, `files.tidy_apply` — исполнение с пересчётом плана. Мета `agent.skills`, `agent.why`, `agent.journal`, `agent.learn`.
- `agent/ui.py` — страница `/ui` на порту агента (только loopback, без внешних ресурсов): выбор навыка, параметры, «Выполнить», ожидающие подтверждения, реестр с риском и доступностью, журнал.
- `agent/window.py` — обёртка `pywebview`: если нет — печатает адрес, не ломается.
- `agent/capabilities.py` — статика `files`, `sqlite`, `tray`, `window` с причинами, `dynamic` для панели и модели.
- `agent/config.py` — папки ассистента, своя база, модель, флаг окна.
- `agent/server.py` — порт 8799 теперь личный ассистент: `/skills`, `/skill` (write через подтверждение, kind=skill), `/journal`, `/ui`, `/pending`, `/action/confirm` общий с кликами. Окно при старте, если `PRINTFLOW_ASSISTANT_WINDOW=1`.

### Панель: ответ по фактам базы и день

- `connector/printflow/assistant_knowledge.py` — `keywords_of` без стоп-слов, `topics_of` по словам, `_fact` с ref, `_safe` с пометкой, `retrieve` — факты из Search, Accounting summary/debts, Repo orders/customers/spools, Manager snapshot, Planner day_plan, Shelf items, Events; уникализация и лимит 40. `facts_text` — источник для модели. `_numbers` — цифры ответа против фактов. `answer` — вопрос → факты, без модели — факты и причина, с моделью — ответ + сверка чисел + предупреждения. `day` — briefing/summary детерминированно, текст предложениями для озвучки, числа из тех же сервисов, что панели.
- `connector/printflow/assistant.py` — `complete` (общий вход для модели), `_get_json`, `agent_skills` (реестр агента по loopback).
- `connector/printflow/routes_assistant.py` — 10 маршрутов (было 7): `ask`, `day`, `skills` добавлены, все только читают.
- `site/assistant.html` — карточки «Ответ по фактам базы» (факты с источниками и сверка чисел), «День цеха» (утро/итог без модели), «Навыки ассистента компьютера» (реестр агента с причиной). `sw.js` v84.

## Границы и что не делали

- Облака, публикация порта ассистента наружу, VPN-туннели, обучение весов моделей, постоянно открытый микрофон, непрерывная запись экрана, удаление файлов навыком, автоответ клиенту и автопечать без подтверждения, второй бот и помощник на телефоне — не делаем (решение владельца и инварианты).
- Трей `pystray` и `pywebview` — необязательные зависимости: без них окно открывается страницей, агент честно говорит причину (capabilities).
- Голос (Н27–Н33, Н41–Н45) и окна/приложения (Н16–Н26) и зрение (Н35–Н40) — следующие заходы 18.15.0–18.17.0.

## Как проверить на живой машине

1. `cd agent && python -m venv .venv && .venv\Scripts\activate && pip install -r requirements.txt`
2. `set PRINTFLOW_ASSISTANT_FOLDERS=C:\Users\вы\Documents` и `set PRINTFLOW_MODEL_NAME=qwen2.5:7b`
3. `python -m agent` — агент печатает адреса, окно на `http://127.0.0.1:8799/ui`, способности честно.
4. В окне: `files.index`, затем `files.search` со словом из документов, `day.briefing` (нужна панель).
5. `files.tidy_plan` — план раскладки загрузок; `files.tidy_apply` — подтверждение, без него файлы не двигаются.
6. `agent.why` на любом навыке объяснит отказ; `agent.journal` покажет след.
7. Панель `http://127.0.0.1:8765/assistant.html` — карточки «Ответ по фактам базы», «День цеха», «Навыки ассистента компьютера».
