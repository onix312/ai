# ТЗ: Telegram-бот на кнопках — релиз 15.4 (первая версия)

Составлено по ответам заказчика (Раунды 1–3, 04.09.2026).
Исполнитель: Arena-агент. Заказчик: владелец PrintFlow.

---

## 1. Цель

Внутренний Telegram-бот переходит на **кнопки без обязательных команд**.
Текст остаётся только для сумм, количества и имён. Команды работают,
но скрыты — никто не обязан их знать. Заказчик проверяет результат
в Telegram (тестовый токен).

## 2. Запреты (не входят в релиз)

- Новые отчёты и аналитика (существующие текстом — позже переведу на кнопки).
- Общие запреты репозитория: ночная смена, авто-перепечатка без
  подтверждения, PIN в LAN, свой слайсер, голосовой ввод, облачный
  CRM/автопостинг, новые генераторы ценников.
- Права ролей и онлайн-деньги — не переделываем (оставляем как есть).

## 3. Главное меню (reply-клавиатура, гибрид)

```
🛒 Продать   📦 Полка   💰 Касса
📷 Кадр      📊 Итоги   ⚙️ Ещё
```

- **Продать** — топ недели → товар → количество → цена → канал → ✅ подтверждение.
- **Полка** — список позиций (остаток, цена, цвет по минимуму) → карточка:
  Продать / Приход / Списать / Пересчёт / История / Резерв.
- **Касса** — выемка / приход / сверка / итог дня / деньги на счёте.
- **Кадр** — последний кадр камеры сразу.
- **Итоги** — сегодня / неделя / месяц / долги / брак (существующие текстом, кнопки выбора).
- **Ещё** — очередь печати, заказы, клиенты, принтеры, катушки, доктор, команда, настройки.

## 4. Сценарии первой версии

### 4.1 Продажа
1. «Продать» → топ за 7 дней + «Все товары».
2. Выбор товара (кнопки, пагинация) → количество (1/2/5/10 + своё).
3. Цена: по умолчанию / «своя» (скидка) → подтверждение на кнопке.
4. Канал: «Полка» (в кассу) или «Онлайн» (Авито/ТГ — на счёт).
5. Итог: ✅ «Продано: Адресник ×2 = 1 000 ₽ (полка). Остаток: 8».
   Кнопки рядом: «Продать ещё», «Забрали деньги», «Готово».

### 4.2 Касса
- Выемка: быстрые суммы (500/1000/всё) + своя → комментарий кнопками →
  фото чека (опционально) → подтверждение → запись.
- Приход: аналогично.
- Сверка: бот показывает ожидаемый остаток → ввод факта → разница (0 / ±).
- Итог дня: продажи + приход − выемки; онлайн отдельной строкой.

### 4.3 Печать (в «Ещё» → Очередь)
- Очередь кнопками: задание → Пауза / Стоп / Продолжить / Кадр / Готово.
- «Что печатаем сегодня» — план. «Следующее» — бот выбирает сам.
- «Снял деталь» — кнопка по готовности.

### 4.4 Заказы и клиенты
- Заказ: товар кнопками → клиент (список/поиск) → предоплата/долг →
  статус кнопками → «Выдать» с чеком.
- Клиент: карточка кнопками: Заказы / Покупки / Долг / Напомнить / Заметка.

### 4.5 Уведомления (всё, тихие часы 22–8)
- Готовность печати с фото → «Снял» / «Не снял».
- Низкий остаток → «Заказать».
- Выемка/продажа больше лимита → владельцу.
- Ошибка/стоп принтера с кадром.
- Заказ готов → «Позвонить клиенту».
- Долг > 30 дней → «Напомнить».

## 5. Права (существующие, без изменений)

Гость: Полка + Кадр. Продавец: + Продать (без себестоимости/маржа).
Менеджер: + Касса, Заказы, Клиенты, Итоги (без налогов).
Владелец: всё + «Команда», «Настройки». Недоступное — кнопка «Показать владельцу».

## 6. Тон бота

По делу + эмодзи-статусы. Коротко: «✅ Продано: 2 × Адресник = 1 000 ₽.
Остаток: 8». Никакой «болтовни».

## 7. План итераций

1. **И1 — каркас**: главное меню (reply) + навигация «Назад/В главное» +
   inline-диспатчер; все существующие функции доступны кнопками;
   команды скрыты из «Помощи», но работают. Тесты.
2. **И2 — Продажа кнопками** (топ, количество, цена, канал, подтверждение).
3. **И3 — Касса кнопками** (выемка, приход, сверка, итог).
4. **И4 — Печать и очередь кнопками**.
5. **И5 — Заказы, клиенты, долги кнопками**.
6. **И6 — Уведомления** (готовность, остаток, лимит, ошибки, долги) + тихие часы.
7. **И7 — Тон, полировка, полный прогон тестов, CHANGELOG 15.4, коммит.**

«Когда всё работает»: заказчик проходит сценарии 4.1–4.5 в Telegram
(тестовый токен) без открытия панели. Каждая итерация завершается
`pytest`, `py_compile`, `node --check`; перед релизом — полный прогон.
