# NOZZA Memory 2.0

Память ассистента остаётся в отдельной SQLite-базе. Четыре слоя — это
представления уже существующих данных:

- **Working** — последние реплики текущего диалога.
- **Episodic** — недавние фактические действия из журнала, без параметров,
  которые могут содержать личные данные.
- **Semantic** — факты, люди и правила.
- **User Model** — профиль и предпочтения владельца.

`GET /memory?session=native` возвращает прежний список `memories` и новый объект
`layers`. Запись памяти содержит `source`, `created_at`, `provenance`, `origin`,
`confidence` и `observed_count`. Публичные `created_at` и `observed_count`
отображают старые поля SQLite `at` и `evidence_count`; копия данных не создаётся.

`origin` бывает `explicit`, `observed`, `inferred` или `imported`. Значение
определяет доверенный путь записи, поэтому самообучение не может назвать
догадку явным фактом. Запись, предложенная моделью через навык, тоже считается
предположением; слова владельца и ввод в окне считаются явными. Повторное
подтверждение увеличивает счётчик. Более слабая
или менее уверенная запись не заменяет противоречащий профиль либо предпочтение.
В ответах и контексте модели предположения и наблюдения названы явно.

Миграция добавляет колонки без удаления прежних записей. При повторном запуске
она сохраняет уже выставленную уверенность.
