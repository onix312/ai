# Voice Engine 2.0

NOZZA теперь имеет постоянный локальный голосовой режим, похожий по поведению на
обычный голосовой ассистент. PrintFlow для него не требуется.

## Поток

```text
IDLE
  │ локальный VAD + ASR
  ▼
WAKE WORD «Ноза»
  ▼
LISTENING
  ▼
THINKING
  ▼
SPEAKING
  │
  ├─ «стоп / хватит» → прервать TTS
  │
  └─ конец ответа → FOLLOW-UP WINDOW
                      │
                      ├─ новая фраза → THINKING
                      └─ таймаут → IDLE
```

В idle речь распознаётся локально, но не передаётся в Brain, пока не услышан wake
word. Запись на диск не ведётся. Для faster-whisper используется только его
существующий временный файл, который удаляется сразу после транскрипции.

## Разговор

Пример:

```text
— Ноза, что у меня сегодня?
— В 18:00 напоминание...
— А завтра?
— Завтра...
— Стоп.
```

Повторять «Ноза» для «А завтра?» не требуется: после ответа открыт короткий
follow-up interval. По умолчанию это 8 секунд.

## Barge-in

Пока NOZZA говорит, аудио не считается новой командой. Это защищает от того,
чтобы ассистент услышал собственный TTS и начал отвечать сам себе. Исключение —
явная короткая команда «стоп», «хватит», «тихо», «замолчи», «остановись».

TTS-процесс отслеживается в `agent.pc` и может быть завершён немедленно.

## API

Speech port, по умолчанию `127.0.0.1:8791`:

- `GET /voice/status`
- `POST /voice/enable`
- `POST /voice/disable`
- `POST /voice/stop`

Старые `/mic/arm` и `/mic/disarm` сохранены.

## Настройки

- `PRINTFLOW_VOICE_ALWAYS_ON=1`
- `PRINTFLOW_VOICE_FOLLOWUP_SECONDS=8`
- `PRINTFLOW_VOICE_VAD_THRESHOLD=320`
- `PRINTFLOW_VOICE_SILENCE_SECONDS=0.8`
- `PRINTFLOW_VOICE_MAX_PHRASE_SECONDS=15`
- `PRINTFLOW_SPEECH_MODEL_PATH=` — необязательный явный путь к Vosk.

Если путь не задан, Vosk-модель ищется в `models/`,
`~/.printflow/models/` и `agent/models/`.

## UI

Tray управляет именно постоянным wake-word режимом, а не коротким arm-окном.
Voice Orb получает состояние `idle/listening/thinking/speaking/error` из
agent core и не пытается угадывать его самостоятельно.

## Ограничение текущего среза

Barge-in останавливает именно озвучку. Уже начатый запрос к большой текстовой
модели пока не отменяется на уровне рантайма; это отдельная задача Task/Model
cancellation.
