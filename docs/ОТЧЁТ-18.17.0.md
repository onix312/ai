## Как проверить на живой Windows-машине

1. `cd agent && python -m venv .venv && .venv\Scripts\activate && pip install -r requirements.txt` (pywebview, Pillow, pystray опционально)
2. `python -m agent` — агент на 8799, окно `/ui`, capabilities покажут system, clipboard, window, screen.
3. В окне: `system.process_list` → топ процессов, `system.health` → диск/память, `system.autostart` enabled=true → запись в HKCU Run.
4. `window.active` / `window.list` → активное и список, `window.focus` title=часть заголовка → фокус с подтверждением.
5. `clipboard.read` → читает буфер и сохраняет в историю, `clipboard.history` → 20 последних.
6. `screen.shot` → размер PNG, `screen.region_shot` left/top/right/bottom → область.
7. `voice.profile` speed=быстро tone=деловой → сохраняет в preferences, `knowledge.preferences` → список.
8. `safety.whitelist_save` app_name=Chrome allowed=true → белый список, `window.click` x/y → проверка whitelist.
9. `scheduler.focus_timer` minutes=25 note=печать → таймер, `focus_list`.
10. `files.watch` path=~/Downloads → слежка, `files.quick_open` name=3d → rglob.
11. `assistant.macro` name=my.утро steps=[{skill:day.briefing},{skill:files.recent}] → макрос, `macro_run` с подтверждением.
12. Панель `http://127.0.0.1:8765/assistant.html` — новые карточки, подтверждение для кликов/питания/whitelist/макросов.
