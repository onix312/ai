## Что сделано

### Установщик

- `agent/install.py` (новый, stdlib+pip):
  - `REQUIRED = mss, Pillow, pywebview, pystray`, `VOICE = vosk, sounddevice`, `OCR = rapidocr-onnxruntime`, `OPTIONAL = faster-whisper`.
  - `check()` — что есть: `_has_module` для 8 модулей, `shutil.which` для tesseract/ollama, `~/.printflow/models` для vosk-моделей, `needs_install`.
  - `_pip_install` — `sys.executable -m pip install --upgrade` с таймаутом 300с.
  - `install()` — ставит только недостающее по маппингу missing→pip-spec, возвращает отчёт.
  - `install_requirements()` — из `requirements.txt`.
  - `download_vosk_model(name)` — скачивает `vosk-model-small-ru-0.22.zip` из alphacephei.com в `~/.printflow/models`, распаковывает zip, удаляет zip.
  - `full_setup()` — pip + модели + external check, `ok = all(steps ok)`.
  - CLI `--check/--install/--requirements/--models/--full` с JSON выводом.

## Как пользоваться на живой машине

1. `cd agent && python -m agent.install --check` — что не хватает.
2. `python -m agent.install --install` — поставить только недостающие pip-пакеты.
3. `python -m agent.install --models` — скачать vosk small ru (~50 МБ) в `~/.printflow/models`.
4. `python -m agent.install --full` — всё сразу.
5. Панель `assistant.html` → «Автоустановка» → Проверить → выбрать what → ввести «установить» для моделей/full → Установить (с подтверждением).
6. После установки `python -m agent` — capabilities покажут всё зелёным, `system.health`, `window.active`, `clipboard.read`, `screen.shot` станут доступны.
