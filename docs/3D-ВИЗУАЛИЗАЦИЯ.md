# 3D-визуализация в PrintFlow 12.5.0

Релиз 12.5.0 добавляет 3D-визуализацию моделей и G-code в панель PrintFlow.

## Компоненты

### 1. G-code viewer (`gcode-viewer.js`)
- **Без зависимостей** — работает сразу
- Парсит G-code послойно, рисует SVG
- Слайдер слоёв, play/pause анимация
- Статистика: слои, время, вес

**Использование:**
```javascript
const gcode = await fetch('/api/job/gcode/123').then(r => r.text());
GCodeViewer.create(document.getElementById('viewer'), gcode);
```

### 2. STL/3MF viewer (`stl-viewer.js`)
- **Требует Three.js** (~600 КБ)
- Парсит бинарный STL, рендерит 3D-сцену
- Вращение мышью, зум колесом
- Статистика: треугольники, размер, объём

**Использование:**
```javascript
const buffer = await fetch('/api/model/stl/456').then(r => r.arrayBuffer());
STLViewer.create(document.getElementById('viewer'), buffer);
```

## Установка Three.js

STL viewer требует Three.js. Скачайте и поместите в `site/assets/`:

```bash
# Вариант 1: wget
wget https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.min.js -O site/assets/three.min.js

# Вариант 2: curl
curl -o site/assets/three.min.js https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.min.js

# Вариант 3: вручную
# Скачайте с https://threejs.org/download/ и поместите в site/assets/three.min.js
```

После этого добавьте в HTML:
```html
<script src="/assets/three.min.js"></script>
<script src="/assets/stl-viewer.js"></script>
```

## Интеграция в панель

### Очередь печати (идеи 29, 30)
Мини-превью G-code в строке задания:
```javascript
// В queue.js
if (job.gcode_preview) {
  const preview = GCodeViewer.render(job.gcode_preview.layers, 0, { width: 64, height: 64 });
  row.innerHTML += `<div class="job-preview">${preview}</div>`;
}
```

### Карточка заказа (идея 31)
3D-модель изделия:
```javascript
// В order.js
if (order.model_stl) {
  const buffer = await fetch(`/api/model/stl/${order.model_id}`).then(r => r.arrayBuffer());
  STLViewer.create($('order_3d'), buffer);
}
```

### Карточка товара (идея 32)
3D-превью для витрины:
```javascript
// В products.js
if (product.model_stl) {
  STLViewer.create($(`product_3d_${product.id}`), product.model_stl);
}
```

### Калькулятор (идея 33)
Визуализация плиты:
```javascript
// В calc.js
GCodeViewer.create($('calc_preview'), gcodeText);
```

### Библиотека моделей (идея 34)
Галерея thumbnail:
```javascript
// В library.js
for (const model of models) {
  const preview = GCodeViewer.render(model.gcode.layers, 0, { width: 128, height: 128 });
  gallery.innerHTML += `<div class="model-card">${preview}<h3>${model.name}</h3></div>`;
}
```

## API

### GCodeViewer
```typescript
parse(gcode: string): { layers: Layer[], stats: { layers, time, weight } }
render(layers: Layer[], layerIdx: number, opts: { color, width, height }): string
create(host: HTMLElement, gcode: string): void
```

### STLViewer
```typescript
parse(buffer: ArrayBuffer): { vertices, normals, triangles }
create(host: HTMLElement, buffer: ArrayBuffer, opts: { width, height, color }): void
```
