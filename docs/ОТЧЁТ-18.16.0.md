## Как проверить на живой машине

1. `cd agent && python -m agent` — агент на 8799, окно `/ui`.
2. В окне: `avito.watch` «3d принтер, Москва», `avito.check` → новые в `avito.listings`.
3. `avito.thread_save` с текстом переписки → 3 варианта для копирования, без отправки.
4. `avito.threads` → архив.
5. `avito.dedup` → группы по `image_hash` (первые 32KB).
6. `avito.to_order` listing_id → черновик заказа, подтверждение в панели.
7. `tg.template_save` «Кейс» с `{topic} {fact}` → `tg.templates`.
8. `tg.template_apply` template_id + facts → черновик.
9. `tg.hashtags` «PETG адресник подарок» → `#3dпечать #petg #адресник`.
10. `tg.search` «PETG» → FTS по черновикам.
11. `tg.schedule` draft_id + `2026-09-23 10:00` → календарь, `tg.schedules`.
12. `tg.export?format=md` → экспорт.
13. `tg.stats` → идеи: total/used/conversion, черновики posted.
14. Панель `http://127.0.0.1:8765/assistant.html` — новые карточки, копирование в буфер, подтверждение для `to-order`.
