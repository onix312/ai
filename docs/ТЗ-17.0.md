# ТЗ · PrintFlow 17.0 — глобальное обновление интерфейса

> Согласовано с заказчиком 2026-09-06 (3 раунда вопросов, трекер —
> `docs/РЕДИЗАЙН-17.0.md`). Мажорная версия: полный редизайн и реструктуризация
> фронтенда. Бэкенд (учёт, деньги, печать, боты) стабилен и не переписывается.

## 1. Цель

Современный, единый, мобильный и доступный интерфейс NOZZA · PrintFlow:
дизайн-система на токенах, навигация из 4 групп с хабом страниц, все 222
настройки управляемы из панели (включая «Кассу 16.0»), фронтенд разбит на
модули, публичные страницы переведены на токены.

## 2. Зафиксированные решения (кратко)

1. Тёмная тема — по умолчанию; переключатель «система/светлая/тёмная» на всех страницах.
2. Акцент — бренд-индиго `#4f46e5 → #7c3aed`; выбор акцента в настройках остаётся.
3. Стиль — гибрид: панель плотная (data-first), публичные/мобильные страницы воздушные.
4. Шрифт — Inter (variable, woff2, кириллица+латиница) локально в репозитории; моно — JetBrains Mono; без CDN.
5. Меню — 4 группы: **Цех · Продажи · Касса · Система** (карта в трекере).
6. Хаб «Страницы» — отдельная вкладка в «Системе»: все 14 LAN-страниц карточками, QR для телефона, пометки «телефон/ТВ/публичная», замок на кассовых.
7. Настройки — гибридная форма: простые поля из `/api/settings/schema` (META на все 222 ключа), сложные блоки — ручные карточки; поиск по всем настройкам; «Показать все» для технических ключей.
8. Касса — три отдельные вкладки настроек: «Касса» · «СБП» · «Банк».
9. Редизайн и модуляризация — вместе, вкладка за вкладкой.
10. Фронтенд-стек — **Lit + Vite со сборкой**; делаем **автоматический сборщик** (`scripts/build_frontend.py`: сам ставит npm-зависимости и собирает); собранный бандл коммитится — запуск без Node работает как раньше.
11. Охват — все 6 итераций; приёмка в конце.
12. Группа меню «Касса» содержит вкладку «Финансы» и ссылки «СБП · входящие», «Мобильная касса», «Поступления банка».

## 3. Границы (не обсуждается)

- Не трогаем: `accounting.py`, `sbp.py`, `cashier.py`, `bank_receipts.py`,
  `receivables.py`, `stock.py`, `month_close.py`, схемы БД денег.
- Бэкенд — только аддитивно (новый эндпоинт/поле при нехватке данных интерфейсу).
- `DEFAULT_SETTINGS` — 222 ключа, не удалять/не переименовывать; новые ключи — только по просьбе заказчика.
- Старые адреса и `data-view`-имена работают: `/m`, `/order`, `/track`, `/shelf`, `.htm` и т.д.
- Тесты: 1311 + `check.py` остаются зелёными (осознанные обновления — с записью в отчёт).
- Версия: `APP_VERSION = "17.0.0"`; тесты с захардкоженной версией обновляются.
- Кэш: при правке статики — `?v=17.0.0` и подъём кэша `sw.js` (`printflow-shell-v27`).

## 4. Итерации

**И0 — Дизайн-система и карта меню.** Версия 17.0.0; Inter/JetBrains Mono
локально + `@font-face`; тёмная по умолчанию (бутстрап-скрипт в `<head>` всех
страниц, без мигания); расширение `tokens.css` (типографика, компонентные
токены кнопок/карточек/тостов/модалок/состояний); скелет сборки Vite+Lit с
автосборщиком; заморозка карты IA.

**И1 — Навигация и хаб.** Новое сгруппированное меню (4 группы) с подписями;
вкладка «Страницы» (хаб): карточки 14 страниц + QR (наш `qr.js`), замки,
категории; быстрые ссылки на кассу/СБП/банк в группе «Касса»; перекрёстные
ссылки; бредкрамбы; подсветка активного пункта; мобильный выезд меню.

**И2 — Цех.** Dashboard, Принтеры, Очередь, Заказы (канбан), Центр 10.0 —
на новой системе: карточки, состояния (hover/active/disabled/loading/empty),
тёмная/светлая сквозная, сводки СБП/кассы на дашборде.

**И3 — Продажи и касса.** Склад/товары/партии, Калькулятор, Клиенты, Ниши,
Контент, Финансы; кассовые страницы (`sbp/cashier/bank`) вписаны в интерфейс
ссылками и сводками; единые состояния.

**И4 — Настройки.** META на все 222 ключа (группа+подпись, min/max/choices);
гибридная форма (схема + ручные блоки); вкладки «Касса»/«СБП»/«Банк»;
поиск по настройкам; режим «Показать все (222)»; проверка
`validate()`/`diff_defaults()`.

**И5 — Мобильные и публичные страницы.** `m/shelf/order/track/my/spool/tv/
labels/price-tags/design` + `sbp/cashier/bank` — на токенах (убрать локальные
палитры), единый тумблер темы, мобильная вёрстка, офлайн.

**И6 — Модуляризация и производительность.** Per-view Lit-модули через Vite;
CSS слоями (`tokens → base → components → views`); ленивая загрузка; a11y-аудит
(фокус, aria, контраст, reduced-motion); пустые/загрузочные/ошибочные
состояния; состояние «коннектор недоступен»; кэш `?v=` и `sw.js`.

## 5. Приёмка (сценарии заказчика)

1. Из панели в 1 клик (с телефона в LAN) открываются все страницы, включая кассу, «СБП · входящие», «Поступления из банка»; тема едина.
2. Тёмная/светлая тема переключается и действует на всех страницах; по умолчанию тёмная.
3. В панели есть вкладки настроек «Касса»/«СБП»/«Банк»: счёт СБП, статический QR, код кассы, авто-подтверждение, окно сопоставления меняются без правки API.
4. Все 222 настройки имеют подпись и группу; поиск находит любую.
5. Тесты зелёные, `check.py` зелёный, старые закладки работают.

## 6. Отчётность

После каждой итерации: запись в `CHANGELOG.md`, отчёт в `docs/ОТЧЁТ-17.0.x.md`,
обновление статусов в трекере. Финальная приёмка — на телефоне в LAN и в панели.
