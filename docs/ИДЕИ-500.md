# Идеи 15.3+ — банк «500 идей» — 4 сентября 2026

Второй каталог: 500 идей в новом ключе. Владелец решил:
**бота переводим на кнопки без обязательных команд** — команды остаются
скрытым способом для опытных, но ни одна функция не требует текста.
Приоритет: **автоматизация** (система сама делает рутину), **польза**
(деньги и время), **удобство** (один тап вместо цепочки).

Каждая идея — одна функция, без разбивки «создать / изменить / скрыть /
удалить»: это вариации одной функции и отдельными идеями не считаются.

Правила те же: номера подряд, статусы **⏸ предложено** · **✅ сделано** ·
**⚡ согласовано** · **❌ не берём**. Запреты репозитория соблюдены
(ночная смена, авто-перепечатка без подтверждения, PIN в LAN, свой
слайсер, голосовой ввод, облачный CRM/автопостинг, генераторы ценников).

## 001–020. Бот: кнопки вместо команд

13. кнопка «Готово» после каждого действия с понятным итогом
