## Контракт «деньги не ломаются» (реализовано и покрыто тестами)

| Требование | Как обеспечено |
|---|---|
| Поступление ≠ выручка | факт из банка лишь находит платёж; выручка — только через `sbp.confirm` |
| Строгое авто-подтверждение | точная сумма + ровно один ожидающий платёж в окне времени (`sbp_match_window_hours`, 24 ч) |
| Никакого молчаливого подтверждения | неоднозначность/отсутствие кандидата → «на сверку» с причиной |
| Нет дублей | импорт идемпотентен по `external_key`; повторная выписка не задваивает |
| Отключаемо | `sbp_auto_confirm=false` → поступление только связывается (`matched`), без проводки |
| Видно и обратимо | статусы поступления (`new/matched/confirmed/review/unmatched`), ручная привязка `link` и подтверждение `confirm`, аудит каждого действия |

## API

- `GET /api/bank/state` — сводка + очередь «на сверку».
- `GET /api/bank/receipts?status=&limit=` — журнал поступлений.
- `POST /api/bank/import` (`csv` или `rows`) — разнести выписку.
- `POST /api/bank/link` (`receipt_id`, `payment_id`, `confirm?`) — привязать вручную.
- `POST /api/bank/confirm` — подтвердить привязанный платёж.

## Формат выписки

Парсер толерантен: `;`/`,` разделители, ключевые слова в заголовках
(«Дата операции», «Сумма», «Назначение», «Контрагент»), доход `amount>0`,
даты в форматах ДД.ММ.ГГГГ и ISO, суммы «1 234,56», «(500,00)», «123,45-».

## Как проверить заказчику

1. Выгрузите выписку Т-Банка (CSV) за день.
2. Откройте `http://<IP-сервера>:8080/bank.html`, вставьте выписку → «Разнести».
3. Совпавшие по сумме и времени платежи подтвердятся сами; сомнительные
   появятся в «На сверку» — привяжите к платежу и подтвердите вручную.
