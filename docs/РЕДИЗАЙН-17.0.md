## Карта меню 17.0 (утверждена, решение №5/№13)

| Группа | Пункты |
|---|---|
| **Цех** | Обзор (dashboard) · Принтеры · Очередь · Заказы · Центр 10.0 |
| **Продажи** | Склад (товары/партии/документы/стеллажи/инвентарь) · Калькулятор · Клиенты · Ниши · Контент |
| **Касса** | Финансы (учёт/налоги/прибыль/долги) · СБП · входящие → · Мобильная касса → · Поступления банка → |
| **Система** | Клиент-бот · Библиотека · Страницы (хаб) · Настройки |

- `inventory` (инвентарь пластика) и `marketing` (контент-студия) — в основном меню (внутри «Склад» и «Продажи» соответственно), не прячем.
- Хаб «Страницы»: все 14 LAN-страниц карточками + QR для открытия с телефона; кассовые помечены замком и требуют код; `tv.html` — в хабе с пометкой «ТВ».
- Старые адреса (`/m`, `/order`, `/track`, `/shelf`, `.htm` и пр.) и `data-view`-имена вкладок сохраняются.

## Принципы (зафиксированы промптом, не пересматриваем)

1. Деньги/данные/склад/проводки — не трогаем; бэкенд только аддитивно.
2. `DEFAULT_SETTINGS` (222 ключа) — источник правды; ключи не удаляем/не переименовываем.
3. Палитра — только в `tokens.css`; новые страницы свою палитру не заводят.
4. Иконки — только реестр `icons.js`; статусы/каналы — без копий.
5. Мобильный вид не хуже десктопного; офлайн (PWA) обязателен.
6. `prefers-reduced-motion`, контраст, фокус, aria-метки.
7. При правке статики — `?v=` у ассетов и версия кэша `sw.js`.
