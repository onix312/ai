## Состояния и путь к действию

| Поверхность | Данные | Загрузка | Пусто | Ошибка или устаревшие данные |
|---|---|---|---|---|
| Основная панель | Текущий экран и заголовок | Каркас/скелетон, без подмены фактов нулями | Сообщение с действием для начала или сброса фильтра | Причина и повтор; сохранение введённого текста |
| Принтер и очередь | Статус задания, телеметрия, отдельная камера | Ожидание телеметрии | Нет принтеров/заданий | «Связь потеряна», возраст данных; отсутствие кадра отдельно от печати |
| Заказы, склад, финансы | Список и фильтры | Скелетон списка | «Нет записей» или «Ничего по фильтру» | Ошибка API не выглядит как пустая база |
| Помощник | Ответ с источником | Подключение/ответ модели | Начало разговора | Модель недоступна; точные данные панели открываются отдельно |
| Отдельные и клиентские страницы | Своя задача и навигация назад | Ожидание API | Предметный пустой экран | Ошибка связи, без ложного статуса успеха |

Это **контракт состояний для D04**, а не утверждение, что каждая текущая страница уже его выполняет. До переноса найдены неполные состояния: часть внутренних разделов имеет скелетон, но не предметную ошибку; отдельные страницы используют разные схемы оформления; версия `refine.css` расходилась между страницами.

## Аудит ресурсов и кэша

- Главная страница подключала шесть CSS с разными версиями (`17.0.1`–`18.22.2`), а утилиты — `refine.css` с `18.22.2` либо `18.22.3`. Ленивая загрузка в `core.js` брала версию самого `core.js`, поэтому её версия могла расходиться с изменённым модулем.
- `sw.js` подготавливал оболочку по адресам без `?v=`, а страницы ссылались на них с параметром. Офлайн-запрос не находил подготовленную копию. Также новый воркер активировался после частичной загрузки оболочки и удалял старый кэш. Исправление требует полной загрузки до активации и поиска по пути файла.
- Релизная версия статических ресурсов после D02–D04 должна быть одна на всех рабочих HTML; имя кэша service worker меняется вместе с ней. Прототип D01 версионируется отдельно.
- Папка `site/assets/dist/` содержит готовый бандл Lit; боевой сервер не должен требовать сборки Node. Сборка меняется только если изменены исходники `frontend/src/`.
