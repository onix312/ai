# Desktop Perception 2.0

`desktop.observe` — read-only навык ассистента. Он возвращает окно, элементы,
элемент с фокусом, источники данных и предупреждения. `title` выбирает окно,
`limit` ограничивает дерево, `ocr` включает запасное распознавание текста,
`screenshot` добавляет сведения о снимке и локальный адрес `/screen`.

Порядок: состояние окна через Win32 → дерево UI Automation → классические
Win32 элементы → OCR, когда элементы не отдали текст → снимок по запросу.
`screen.describe` использует эти данные и обращается к локальной видящей модели
лишь когда текст не найден. `screen.find` указывает фактический метод находки.

UI Automation и OCR работают в отдельных процессах с пределами ожидания 6 и
12 секунд. Их ошибка не блокирует основной процесс: результат сохраняет
полученные данные Win32 и сообщает причину в `warnings`. Для UI Automation
нужен `pywinauto`; для OCR — `rapidocr-onnxruntime` и `mss`. Все три зависимости
указаны в `agent/requirements.txt`. Снимки не сохраняются на диск и доступны
только через локальный сервер агента.

Ограничения: некоторые программы скрывают дерево элементов; OCR может неверно
прочитать текст, поэтому автоматический клик по находке остаётся отключённым.
Визуальная модель также может ошибиться, её ответ не считается структурированным
фактом об элементах интерфейса.
