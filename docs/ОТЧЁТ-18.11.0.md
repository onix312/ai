## Отчёт 18.11.0 — пульт станка: регулятор, тракт AMS, шкала слоёв, инциденты, звук; шлюз Studio без «код=-1»

**Статус:** готово (все срезы реализованы и проверены). Базис — 18.10.0.

Задача владельца: автоматизировать и улучшить взаимодействие с принтером и со слайсером,
улучшить визуал сайта и удобство. Утверждённый набор: **52, 54, 65, 69, 70, 72, 73** плюс
«сделать новые функции понятными в использовании и улучшить удобство на своё усмотрение».
Порядок работы по указанию владельца: код без остановок, тесты по окончании всех работ.

### Срез 1. Шлюз Bambu Studio — рукопожатие TLS вне `accept()` (52)
- Причина «код=-1» на исправном шлюзе подтверждена эмпирически: слушающая розетка была
  `SSLSocket`, и `accept()` выполнял рукопожатие блокирующе в потоке приёма; один молчащий
  TCP-клиент останавливал приём для всех остальных.
- `connector/printflow/studio_gateway.py`: `_listen_tcp()` возвращает обычный TCP, контекст
  TLS создаётся один раз и общий для MQTT, FTPS (контроль и PASV-данные) и порта :3002;
  `_accept_loop(sock, handler, tls)` спавнит `_serve_client()`, который делает
  `_tls_accept()` с дедлайном `TLS_HANDSHAKE_TIMEOUT = 8.0` с.
- Счётчики: `tls_handshakes`, `tls_resumed` (по `session_reused`), `tls_handshake_timeouts`
  (молчуны отдельно от `dropped_connections`), `tls_sessions` из `SSLContext.session_stats()`.
  Всё видно в `/api/studio/status` и в карточке шлюза (`site/assets/app.js`).
- Живая проверка на стенде: молчун на :8883 открыт — рукопожатие Studio проходит за 0.00 с;
  сессия с :8883 возобновляется на :3002 (`session_reused=True`, `hits=1`); молчун
  отброшен через 8 с (`tls_handshake_timeouts=1`).

### Срез 2. Ретранслятор SSDP для Studio в другой подсети (54)
- Настройки `studio_relay_enabled` (по умолчанию выкл.) и `studio_relay_targets`
  (IPv4 через запятую) — `config.py`, `settings_schema.py` с подсказками.
- `relay_printers()` берёт станки из БД (адрес + серийник, без виртуального и выключенных),
  `ssdp_notify_for()` формирует NOTIFY с полями станка (`DevModel` по модели, `USN` —
  серийник, `Location` — адрес станка); `_broadcast_notify()` шлёт их всем адресатам вместе
  с объявлением шлюза; адресаты ретранслятора добавляются в `_notify_targets()` как
  unicast на UDP :2021. Шлюз по-прежнему не занимает :2021.
- `announce_now()` + `POST /api/studio/announce` — кнопка «Объявить сейчас» в карточке
  шлюза с отчётом: сколько пакетов, куда, сколько станков.
- Мусор в адресатах фильтруется молча; понятные подсказки в статусе (`relay_note`):
  «ретранслировать нечего…», «адресаты не заданы…».

### Срез 3. Регулятор скорости (69) — `site/assets/knob.js`
- `window.PFKnob.create(el, {value, onChange})`: SVG-ручка, сектор −135…135°, четыре деления,
  подписи Тихо/Стандарт/Спорт/Ludicrous с процентами, подсказка в `title`.
- Управление: перетаскивание (pointer capture), колесо (±1 деление, применение через 420 мс),
  клик по делению, клавиатура (← → ↑ ↓ Home End Enter), ARIA `role=slider`.
- Состояние «ждём подтверждения станка…» до прихода `info.speed_level`; `fail()` возвращает
  стрелку при отказе; звук `tick` на делении.
- Hero-пульт использует ручку вместо четырёх кнопок; `execHeroSpeed()` возвращает результат.

### Срез 4. Тракт AMS (70) — `site/assets/amspath.js`
- `PFAmsPath.render(ams)` → SVG: блоки AMS с четырьмя слотами, катушки с цветом, кольцом
  остатка, меткой материала; пустые слоты пунктиром; внешняя катушка; хаб и ствол к соплу;
  активные трубки «текут» (CSS-анимация штриха, отключается при reduced motion).
- Чипы под картинкой: активный слот, влажность (индекс 1–5 → «сухо…очень влажно»),
  температура, «Заканчивается: N».
- `PFAmsPath.mount(el, ams)` перерисовывает только при смене подписи (`signature`) —
  анимация не сбрасывается кадрами телеметрии. Показан и при простое.

### Срез 5. Шкала слоёв (72) — `connector/printflow/gcode_layers.py` + `site/assets/layers.js`
- Потоковый разбор `.gcode` или `Metadata/plate_N.gcode` из 3MF; маркеры Bambu Studio
  (`; CHANGE_LAYER`, `; Z_HEIGHT`, `; FEATURE`), Orca/Prusa (`;LAYER_CHANGE`, `;Z:`,
  `;TYPE:`), Cura (`;LAYER:`), `; layer num/total_layer_count`, `M73 P R`; без маркеров —
  смена Z при экструзии; дуги G2/G3 → хорды; M82/M83/G92; корзины: наружная/внутренняя стенка,
  заполнение, сплошные, поддержка, юбка/башня, мосты и свесы, прочее.
- Прореживание: коллинеарные точки схлопываются (допуск 0.06 мм), слой ≤ 1200 отрезков,
  координаты в `array('f')`; индекс строится в фоне, кэш на 3 файла по `(path, mtime, size)`.
- Маршруты в `routes_printers.py`: `GET /api/gcode/layers?printer_id=|file=` (индекс или
  `building:true` или `has:false` с причиной) и `GET /api/gcode/layer?layer=N` (отрезки).
- Виджет: канва слоя (бледно предыдущий), полоска расхода пластика с метками текущего и
  выбранного слоя, режим «● Следить», карточка «Слой / Высота / Пластик / По расчёту
  слайсера», подсказка «?». Стенд без канвы (`getContext()` → null) не падает.

### Срез 7. Звуки панели (65) — `site/assets/sound.js`
- Web Audio без файлов: click, toggle, tick, success, finish (3 ноты), warn, alert; разблокировка
  контекста по первому жесту; дребезг 120 мс; без `AudioContext` — тихо и без ошибок.
- Настройки на устройство `pf_sound`: enabled/ui/events/volume/quiet (22:00–7:00); кнопка
  динамика в шапке; карточка «Звуки панели» в настройках с «Прослушать» по каждому сигналу.
- Хуки: `PF.on('notify')` (complete → finish; error/guard/defect/loss/security → alert;
  filament_low/maintenance/pause/dry → warn), тост `bad` → warn (без дубля после события),
  клики команд станка → click.

### Отложено (явно)
- **WebGPU-слайсер в браузере** — не реализован в этом релизе: требует отдельного ADR
  (выбор между compute-шейдерами и WASM-ядром, распределение между сервером и браузером,
  совместимость с профилями P1S) и собственного дизайна. В задачу 18.11.0 не входит.

### Риски и допущения
- Ретранслятор объявляет `DevBind: free` для реальных станков; если станок привязан к
  облачному аккаунту, Studio в LAN-режиме всё равно спросит Access Code — поведение такое же,
  как при прямом обнаружении. По умолчанию выключен.
- Разбор G-code в 100+ МБ идёт в фоне 10–15 с (≈235k строк/с); всё это время виджет
  показывает «Разбираем G-code… слоёв найдено N».
- Звук требует жеста пользователя (политика браузеров): первый сигнал до первого клика
  на странице не прозвучит.
