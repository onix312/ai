## APK: факты и решения

| Факт | Источник | Решение |
|---|---|---|
| Серверный статус APK | `connector/printflow/routes_app.py:15–28` | Сохранить единый endpoint и расширить только при реальной необходимости |
| Сравнение versionCode | `connector/printflow/app_shell.py:129–149` | Сравнивать только новую версию, не допускать downgrade |
| Касса проверяет только при старте/кнопке | `android/app/.../MainActivity.kt:613–681` | Добавить периодическую проверку в жизненном цикле Activity |
| Пульт не проверяет APK | `android/pult/.../MainActivity.kt:65–105` | Добавить безопасную проверку через тот же LAN endpoint |
| Системная установка | `MainActivity.kt:669–679` | Оставить подтверждение и системный установщик; бесшумную установку не обещать |
| Данные WebView | `docs/ANDROID.md`, Android shell tests | Не очищать localStorage и не менять денежную логику |

## Не трогать

- денежные расчёты, цены, платежи, возвраты и права;
- физические размеры и серверную разметку существующих ценников/этикеток;
- маршруты статусов заказов;
- кэшированные ассеты без подъёма версии;
- APK-файлы и ключи подписи в Git;
- существующие визуально отшлифованные панели кассы, пульта и главного дашборда.
