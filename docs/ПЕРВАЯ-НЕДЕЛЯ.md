# Первая неделя — запуск трёх ниш в PrintFlow

> Цель недели — не заполнить склад, а получить первые измеримые сигналы спроса.

## День 1 — система и безопасность

- [ ] Запустить `python pf.py` (или ярлык после `python pf.py install`).
- [ ] Настроить PrintFlow и сделать резервную копию.
- [ ] Подключить P1S в разделе «Принтер»; LAN Access Code вводить только локально.
- [ ] Проверить лицензию каждой коммерческой модели.
- [ ] Уточнить у бухгалтера, кто именно продаёт товар: ИП магазина или отдельный плательщик НПД.
- [ ] Не включать детские игрушки в стартовую матрицу без юридической схемы маркировки и оценки соответствия.

## День 2 — по три образца на нишу

**Питомцы:** адресник, именная табличка, держатель поводка.

**Дом:** держатель кабелей, держатель пульта, органайзер по размеру.

**Бизнес:** QR-стойка, держатель ценника, настольная табличка.

- [ ] Создать позиции в базе изделий.
- [ ] Записать вес, плановое время, материал и цену.
- [ ] Создать задания в планировщике.
- [ ] После печати сравнить плановые часы с фактическими данными Bambu Lab Live.

## День 3 — фото и полка

- [ ] Снять каждый образец при дневном свете.
- [ ] Сделать кадр в реальном использовании, а не только на белом фоне.
- [ ] Разделить полку на три небольшие зоны.
- [ ] Для каждого образца указать цену или диапазон цены.
- [ ] Добавить оффер: «имя и цвет за день», «сделаем по вашим размерам», «для бизнеса с логотипом».
- [ ] Не обещать пищевую безопасность, нагрузку или долговечность без испытаний.

## День 4 — объявления и сообщения

- [ ] Опубликовать отдельное предложение на каждую нишу.
- [ ] Проверить текущие категории, комиссии и способы доставки непосредственно в кабинете площадки.
- [ ] Начать сообщения с проблемы клиента, а не с технологии 3D-печати.
- [ ] В PrintFlow внести показы и обращения по каждой нише.

## День 5 — локальный B2B

- [ ] Выбрать 10 местных бизнесов, где видна конкретная проблема.
- [ ] Написать короткое персональное сообщение с фотографией подходящего образца.
- [ ] Предложить один тестовый макет, а не бесплатную бесконечную разработку.
- [ ] Зафиксировать контакт и следующий шаг.

## День 6 — первые заказы

- [ ] Каждый заказ сразу заносить в PrintFlow.
- [ ] Указывать срок, предоплату, файл, материал и контроль качества.
- [ ] Называть файл с номером заказа: `0007-adresnik-v3.3mf`.
- [ ] Проверять автоматическую связь печати с заказом.
- [ ] После выдачи записывать фактическую прибыль и замечания клиента.

## День 7 — разбор

Для каждой ниши посчитать:

- показы;
- обращения;
- расчёты;
- заказы;
- выручку;
- прибыль;
- часы принтера;
- ручное время;
- брак.

## Критерий успешной недели

Неделя успешна, если система учёта работает, напечатано не более 9–15 осмысленных образцов, получены реальные обращения и понятно, что тестировать дальше. Большой непроданный склад успехом не считается.
