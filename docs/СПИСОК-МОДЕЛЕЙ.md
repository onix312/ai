# Ассортимент и модели — три ниши

## Проверка лицензии

Перед коммерческой печатью откройте страницу исходной модели и сохраните ссылку и снимок условий лицензии.

| Лицензия | Коммерческая продажа |
|---|---|
| CC0 | обычно разрешена |
| CC BY | обычно разрешена с указанием автора |
| CC BY-SA | разрешена при соблюдении Attribution и ShareAlike |
| CC BY-NC / NC | запрещена |
| Personal use only | запрещена |
| Коммерческая подписка автора | только пока выполнены её условия |

Лицензия модели не даёт права использовать чужой товарный знак, логотип или персонажа.

## Ниша 1 — питомцы

| Изделие | Материал для теста | Риск | Формат |
|---|---|---|---|
| Адресник | PETG | проверить отверстие и истирание текста | персональный |
| Табличка с именем | PLA/PETG | низкий | полка + заказ |
| Держатель поводка | PETG | испытать крепёж; не часть поводка | по заказу |
| Диспенсер пакетов | PETG | проверить защёлку | серийный |
| Органайзер ухода | PETG | учитывать влагу | по размерам |
| Крепление для клетки | PETG/ASA | не использовать как запирающий элемент | индивидуальный |
| Декор с силуэтом породы | PLA | низкий | подарочный |

Не включать на старте изделия для разгрызания, основные карабины, ошейники и детали постоянного контакта с кормом.

## Правило серийного ассортимента

Модель становится SKU только после того, как:

- напечатана минимум три раза без критического брака;
- известны фактические часы и расход;
- понятен контроль качества;
- лицензия допускает коммерческое использование;
- есть хотя бы один платный заказ или подтверждённый тест полки;
- прибыль на час соответствует текущей загрузке принтера.
