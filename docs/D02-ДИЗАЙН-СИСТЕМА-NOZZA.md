# D02 · Дизайн-система NOZZA

Утверждённый владельцем D01 перенесён в рабочую оболочку 28 сентября 2026 года. Общие значения хранятся в `site/assets/tokens.css`, оформление компонентов — в `site/assets/refine.css`. Новых зависимостей и сборки нет.

## Темы и контраст

| Роль | Светлая | Тёмная | Применение |
|---|---|---|---|
| Фон / поверхность | `#f5f7fb` / `#ffffff` | `#0c121b` / `#16212e` | Страница / карточка |
| Основной текст | `#182230` | `#f2f6fb` | Заголовки, данные |
| Вторичный текст | `#617186` | `#a0b2c5` | Подписи, пояснения |
| Действие | `#4f46e5` | `#a3a0ff` | Ссылка, фокус, активный пункт |
| Успех / внимание / ошибка | `#116e55` / `#99570a` / `#b93f52` | `#55d1a6` / `#ffc375` / `#ff9daa` | Статусы и сообщения |

Отношение контраста текста к поверхности: светлая тема — 16,03:1 для основного, 4,98:1 для вторичного, 5,39–6,29:1 для акцентных и статусных цветов; тёмная — 14,99:1, 7,49:1 и 6,99–10,31:1. Дополнительные пользовательские акценты получили отдельные светлые оттенки для тёмной темы. Основная кнопка использует `#4f46e5` с белым текстом в обеих темах.

## Каталог общих компонентов

| Компонент | Обычное состояние | Загрузка / пусто / ошибка | Взаимодействие |
|---|---|---|---|
| Навигация | Три рабочие группы и «Все разделы» | Поиск показывает предметное «нет раздела» | Текущий маршрут, клавиатура, мобильная панель |
| Заголовок / панель действий | Короткий заголовок и главное действие | Заголовок остаётся на месте во время загрузки | Действия переносятся на новую строку на телефоне |
| Карточка / KPI | Одна поверхность, единая линия и радиус | Скелетон / пояснение в `.empty` | Видимый фокус у вложенных элементов |
| Таблица | Нейтральная шапка, подсветка строки | Состояния списка выводит экран-владелец | Фокус и hover различимы |
| Фильтры заказов | Основные поля сразу, остальные в «Доп. фильтры» | Число активных дополнительных фильтров видно в заголовке | Escape закрывает панель; выборы сохраняются при навигации |
| Форма / диалог | Единый радиус, границы и фон | Ошибка показывается рядом с формой | Фокус выделяется; повтор не перезагружает страницу |
| Сообщение связи | Причина и кнопка «Повторить» | Не подменяет рабочие записи пустым списком | Повторяет загрузку в текущем экране |

Эта общая основа используется в заказах, принтерах и финансах. Предметные состояния каждой вкладки и специальные печатные страницы переносятся в следующих V01–V06; карта покрытия находится в `S02-КАРТА-ЭКРАНОВ-И-РЕСУРСОВ.md`.
