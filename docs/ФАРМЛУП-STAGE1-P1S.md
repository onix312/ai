# PrintFlow FarmLoop Stage 1 для Bambu Lab P1S

Дата: 14.09.2026. Первый целевой принтер — Bambu Lab P1S.

## Что строим

PrintFlow не становится слайсером на этом шаге. Bambu Studio остаётся источником
траекторий, а PrintFlow получает готовый G-code и создаёт отдельную FarmLoop-версию:

```text
Bambu Studio
  → G-code
  → проверка P1S / Stage 1
  → проверенный FarmLoop-шаблон
  → AMS preflight
  → отдельный G-code
  → очередь PrintFlow
```

Исходный файл никогда не перезаписывается.

## Важное ограничение

G-code не может физически снять деталь без установленной механики. До установки
и ручной проверки бесплатного FarmLoop Stage 1 PrintFlow не активирует реальные
движения. Точные команды изгиба, толкателя и очистки нельзя придумывать: они
зависят от конкретных напечатанных деталей, платформы, высоты и положения P1S.

В репозитории есть профиль `bambu-p1s-farmloop-stage1`, но реальный шаблон должен
быть добавлен после установки комплекта и проверки владельцем.

## Профиль P1S

- Принтер: Bambu Lab P1S
- FarmLoop: Stage 1
- Платформа: 256 × 256 мм
- Предварительный предел высоты при установленной механике: 200 мм
- Источник траекторий: Bambu Studio/OrcaSlicer
- AMS: проверяется отдельно перед запуском
- Результат: отдельный обработанный G-code

## Безопасный конвейер

1. Загрузить G-code из Bambu Studio.
2. Проверить команды температуры сопла и стола.
3. Проверить высоту и предупреждения профиля.
4. Убедиться, что файл ещё не обработан FarmLoop.
5. Проверить точный шаблон с маркерами начала и конца.
6. Добавить только подтверждённый блок.
7. Записать профиль, цикл, AMS и идентификатор задания комментариями.
8. Сохранить отчёт проверки.
9. Поставить отдельный файл в очередь.

Пустой шаблон, повторная обработка или файл без признаков FDM G-code отклоняются.

## Следующий шаг после установки механики

Владелец устанавливает бесплатные печатные детали Stage 1 на P1S и вручную
проверяет:

- свободный ход головы;
- положение толкателя;
- изгиб платформы;
- отсутствие контакта с корпусом;
- безопасную высоту;
- направление сброса детали;
- наличие корзины;
- ручную остановку.

После этого в PrintFlow добавляется реальный проверенный G-code-шаблон и проходит
один тестовый цикл без автоматического продолжения. Только после успешного
теста рассматривается серия из 3, 5 и 10 циклов.

## Ручная подготовка файла

После установки и проверки механики оператор сможет использовать локальную
команду:

```bash
python3 scripts/farmloop-prepare.py input.gcode \
  --template farmloop-p1s-stage1.gcode \
  --output input.farmloop.gcode \
  --job-id demo --cycle 1 --cycles 10 \
  --ams AMS1/3 --material PETG --color black \
  --report input.farmloop.json
```

Команда ничего не отправляет на принтер. Если шаблон не содержит точных маркеров,
реальных команд движения или файл уже обработан, она завершается ошибкой.

## Файлы кода

- `connector/printflow/farmloop.py` — профиль, аудит, проверка шаблона и подготовка файла;
- `scripts/farmloop-prepare.py` — локальная команда подготовки;
- `connector/tests/test_farmloop.py` — поведенческие тесты без принтера;
- `docs/ФАРМЛУП-STAGE1-P1S.md` — ограничения и приёмка.
