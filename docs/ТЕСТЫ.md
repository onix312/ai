# Тесты PrintFlow: поведение и строки

Дата замера: 22.09.2026, версия 18.17.0. Файлов в `connector/tests/` — **163**.

Тесты здесь двух разных видов, и путать их нельзя: один проверяет, что код
работает, второй — что файл выглядит так, как договорились.

| Вид | Файлов | Что проверяет |
| --- | --- | --- |
| Поведение | **105** | Запускает настоящий код: база, репозиторий, маршруты, сервисы. Падает, когда сломалась логика. |
| Поведение + строки | **36** | Запускает код и сверяет текст файлов: вёрстка, ресурсы, документы. |
| Только строки | **22** | Читает файлы как текст: вёрстка, оболочка, метаданные Android, версии. Код не запускается. |
| **Всего** | **163** | |

## Правило

1. Если поведение можно запустить — тест обязан его запускать. Строковый
   контракт вместо прогона кода считается временным и пишется с пометкой,
   почему прогон невозможен: нет браузера, нет устройства, нет Gradle.
2. Строковый контракт годится там, где проверяется сам текст: разметка страницы,
   `sw.js`, `strings.xml`, заголовки документов, числа в справке.
3. Строковый контракт не заменяет поведенческий. Оба вида могут жить в одном
   файле, но в разных классах — как `SiteMarkupTests` и `OrderArchivePanelTests`
   в `test_site_markup.py`.
4. `scripts/panel-check.js` для DOM-логики не годится: его заглушка отвечает
   цепочкой на любой `querySelector`. Нужна проверка клика — это строковый
   контракт или прогон в node по исходному тексту функции. Так проверены
   `ordersSource()`/`filtered()`, чипы каналов принтера и модули пульта 18.11
   (`test_hero_controls`: регулятор, тракт AMS, инциденты, звуки — чистые
   функции модулей прогоняются в node с заглушкой DOM) и конвейер GPU-сечений
   18.12 (`test_gpuslice`: STL, плоскости, сечения, контуры, аналитика —
   CPU-часть `gpuslice.js` в node; WGSL и точки монтирования — строками).
5. Если у модуля есть свой стенд — проверять его стендом, а не строками:
   `scripts/kassa-check.js` (касса), `scripts/pult-check.js` (пульт: команды,
   preflight, идемпотентный запуск, обрыв связи), `scripts/print-check.js`
   (раздел «Печать»: каталог форм по настоящему реестру, сборка параметров,
   лист в окне печати).

Девять файлов 18.13–18.17 — про локального помощника и личный ассистент компьютера:

| Файл | Что держит |
| --- | --- |
| `test_assistant` | Разбор входящего сообщения: предложения по пустым полям, черновик ответа, loopback-предохранитель, честное выключение. |
| `test_order_intake_attachments` | `POST /api/order/intake/upload`: текст и файл клиента в один черновик; заказ маршрутом не сохраняется, фото и пустой файл отклоняются с причиной. |
| `test_assistant_panel` | Каталог действий: каждый маршрут существует, деньги и печать помечены `confirm`, адрес маршрута берётся из каталога, а не из ответа модели; страница `/assistant.html` и команда `pf.py assistant`. |
| `test_assistant_voice_agent` | Голос: рантайм речи на процессоре, запись уходит только в loopback, расшифровка ничего не выполняет; статус агента компьютера. |
| `test_agent_os` | Внешний агент из `agent/`: слушает только 127.0.0.1, жив без зависимостей, действие в чужом окне ждёт подтверждения человека и умирает по сроку. |
| `test_assistant_store` | Своя база ассистента: память, индекс, журнал, заметки, выученные навыки — отдельный файл, без таблиц цеха. |
| `test_assistant_documents` | Чтение файлов без зависимостей: .docx/.xlsx как zip, .gcode только комментарии, .stl метаданные, фото честно отказывается; нарезка с номерами строк, токены без стоп-слов, факты детерминированные. |
| `test_assistant_fileops` | Раскладка загрузок: план отдельно от исполнения, граница папок, назначения — подпапки, удаления нет, коллизии получают новое имя. |
| `test_assistant_skills` | Реестр навыков: данные вместо веток, подтверждение по риску, причина недоступности, параметры по типам, выученный навык только из существующих шагов и всегда с подтверждением. |

Живой голос, стоп-слово, снимок экрана и клик в чужом приложении в CI не
проверяются: для них нет ни Windows, ни микрофона, ни модели. Это записано в
`docs/ПОМОЩНИК.md` как чеки-лист владельцу.

Числа и списки сверяет `connector/tests/test_suite_map.py`: появился файл или
сменился вид — индекс устарел, тест скажет.
