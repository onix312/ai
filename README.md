# 3D-печать на заказ — полный пакет запуска

**Симферополь · Bambu Lab P1S + AMS · ИП магазина + самозанятость · окупаемость за 6 месяцев**

---

## 👉 Начните отсюда

### **`site/index.html`** — сайт со всем содержимым

Дважды кликните на файл — откроется в браузере. Интернет не нужен.

Внутри: 11 разделов руководства, 3 живых калькулятора, материалы на печать. Галочки в чек-листах и цифры в калькуляторах сохраняются.

**Чтобы открывать с телефона** — запустите `site/ЗАПУСТИТЬ-Windows.bat` (или `.command` на Mac). Подробности в `site/КАК-ЗАПУСТИТЬ.txt`.

---

## Что внутри сайта

### 🧮 Калькуляторы
| Инструмент | Что делает |
|---|---|
| **Калькулятор заказа** | База из 25 готовых изделий (драконы, фиджеты, топперы…) — выбрали, и вес/часы подставились. Учёт отхода AMS, выбор канала продаж (магазин / Авито / WB / Ozon) с комиссиями → себестоимость, цена, **заработок чистыми за час печати** и вердикт «брать / отказаться» |
| **Окупаемость** | План по месяцам + сколько часов печати в день нужно для цели |
| **Тест полки** | Редактируемый список позиций: добавляйте свои, сортируйте по ₽/час, вписывайте продажи → вердикт «масштабировать / убрать» + контроль, влезает ли всё в реальные ~110 ч/нед печати одного принтера |

### 📚 Разделы
**Пуск:** Первая неделя · Бизнес-план
**Производство:** Что печатать · Техника печати

**Документы:** ИП и налоги · Юридика и учёт

## 🤖 Работа с ИИ

**`PROMPT-ДЛЯ-ИИ.md`** — готовый промт-контекст. Скопируйте его в начало диалога с любым ИИ
(ChatGPT, Claude, Gemini…), и ассистент сразу будет знать ваш бизнес, оборудование, экономику
и структуру проекта — можно с ходу просить посчитать цену, написать объявление или доработать сайт.

## Файлы проекта

```
ai/
├── README.md                  ← вы здесь
├── PROMPT-ДЛЯ-ИИ.md           ← промт-контекст для ChatGPT/Claude/любого ИИ
│
├── site/                      ← ГЛАВНОЕ, откройте index.html
│   ├── index.html
│   ├── КАК-ЗАПУСТИТЬ.txt
│   ├── ЗАПУСТИТЬ-Windows.bat
│   ├── ЗАПУСТИТЬ-Mac-Linux.command
│   ├── assets/                (стили и скрипты)
│   └── materials/             (печать на A4: ценники, плакат, таблички, памятка)
│
├── docs/                      ← те же тексты по отдельности (.md)
├── финмодель-окупаемости.xlsx ← 8 листов для Excel
└── архив/                     ← старые версии
```

**Excel-финмодель** оставлена отдельно: там журнал заказов, обход B2B, закупка пластика и постоянные клиенты — то, что удобнее вести в таблице.

## ⚠️ Три вещи до запуска

1. **Самозанятость** — приложение «Мой налог», 15 минут, до первой продажи.
2. **Лицензии моделей** — пометка `NC` (non-commercial) = продавать нельзя. Персонажи брендов — нельзя.
3. **Маркировка игрушек** — продажа через кассу магазина требует ИП-схему из раздела «ИП и налоги».
