# 3D-печать на заказ — полный пакет запуска

**Симферополь · Bambu Lab P1S + AMS · ИП магазина + самозанятость · окупаемость за 6 месяцев**

---

## 👉 Начните отсюда

### **`site/index.html`** — сайт со всем содержимым

Дважды кликните на файл — откроется в браузере. Интернет не нужен.

Внутри: 11 разделов руководства, 8 живых инструментов, материалы на печать. Галочки в чек-листах и цифры в калькуляторах сохраняются.

**Чтобы открывать с телефона** — запустите `site/ЗАПУСТИТЬ-Windows.bat` (или `.command` на Mac). Подробности в `site/КАК-ЗАПУСТИТЬ.txt`.

## Что внутри сайта

### 🧮 Инструменты (8 штук)

| Инструмент | Что делает |
|---|---|
| **Калькулятор заказа** | База готовых изделий — выбрали, и вес/часы подставились. Учёт отхода AMS, выбор канала продаж (магазин / Авито / WB / Ozon) с комиссиями → себестоимость, цена, **заработок чистыми за час печати** и вердикт «брать / отказаться» |
| **Окупаемость** | План по месяцам + сколько часов печати в день нужно для цели |
| **Редактор базы изделий** | 🆕 Единый справочник позиций. Добавляйте свои изделия (категория, вес, часы, цена, отход AMS) — они сразу появляются во всех остальных инструментах |
| **Тест полки** | 🆕 Умные вердикты: учитывают **и продажи, и ₽/час, и загрузку принтера**. «Масштабировать» / «поднять цену» / «в другой канал» / «убрать». При перегрузе сам подскажет, какие позиции резать первыми |
| **История недель** | 🆕 Сохраняйте неделю — копится динамика, график выручки, рост/падение в % и сравнение продаж по каждой позиции |
| **Опт B2B** | 🆕 Сетка скидок по тиражу (10/25/50/100 шт): цена, маржа, ₽/час и **пол, ниже которого опускаться нельзя** |
| **Планировщик печати** | 🆕 Соберите очередь → часы, пластик, деньги и ответ «успеваете ли к сроку» |
| **Учёт пластика** | 🆕 Склад катушек, расход, стоимость запаса и главное — **когда заказывать следующую** (с поправкой на долгую доставку в Крым) |
| **Резервная копия** | 🆕 Скачать всё в .json, выгрузить таблицы в .csv для Excel, восстановить на другом устройстве. Напоминает, если копии давно не было |

**Сводка вверху страницы** показывает живые цифры: выручка за неделю, ₽/час, остаток пластика, точка окупаемости и загрузка принтера.

## 🤖 Работа с ИИ

**`PROMPT-ДЛЯ-ИИ.md`** — готовый промт-контекст. Скопируйте его в начало диалога с любым ИИ
(ChatGPT, Claude, Gemini…), и ассистент сразу будет знать ваш бизнес, оборудование, экономику
и структуру проекта — можно с ходу просить посчитать цену, написать объявление или доработать сайт.

---

## Файлы проекта

```
ai/
├── README.md                  ← вы здесь
├── PROMPT-ДЛЯ-ИИ.md           ← промт-контекст для ChatGPT/Claude/любого ИИ
│
├── site/                      ← ГЛАВНОЕ, откройте index.html
│   ├── index.html
│   ├── КАК-ЗАПУСТИТЬ.txt
│   ├── ЗАПУСТИТЬ-Windows.bat
│   ├── ЗАПУСТИТЬ-Mac-Linux.command
│   ├── assets/                (стили и скрипты)
│   └── materials/             (печать на A4: ценники, плакат, таблички, памятка)
│
├── docs/                      ← те же тексты по отдельности (.md)
├── финмодель-окупаемости.xlsx ← 8 листов для Excel
└── архив/                     ← старые версии
```

**Excel-финмодель** оставлена отдельно: там журнал заказов, обход B2B и постоянные клиенты — то, что удобнее вести в таблице. Полка, история недель, склад пластика и очередь печати теперь считаются прямо на сайте и выгружаются в CSV кнопкой «Выгрузить таблицы».

> ⚠️ **Данные хранятся только в вашем браузере.** Раз в неделю заходите в раздел «Резервная копия» и скачивайте файл — очистка кэша или новый телефон иначе сотрут историю.

## ⚠️ Три вещи до запуска

1. **Самозанятость** — приложение «Мой налог», 15 минут, до первой продажи.
2. **Лицензии моделей** — пометка `NC` (non-commercial) = продавать нельзя. Персонажи брендов — нельзя.
3. **Маркировка игрушек** — продажа через кассу магазина требует ИП-схему из раздела «ИП и налоги».
